## Rebuild

From this directory, with Python 3 and Matplotlib already installed:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B render_assets.py
PYTHONDONTWRITEBYTECODE=1 python3 -B build.py
```

CSV and the single vector figure. TeX uses local sources and canonical local

passes, fonts and final warnings. No scientific engine or model is imported.
