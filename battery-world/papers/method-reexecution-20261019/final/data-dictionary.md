# Saved-data dictionary

All paths below are relative to `data`. Data files preserve original bytes. `manifest.json` records `path`, `bytes`, SHA-256 and collection purpose. A raw byte SHA differs from a canonical JSON content hash. Canonical content hashes use UTF-8 `json.dumps(..., ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False)`.

`generated/analysis.json` is a derived output. CSV units follow the source fields: F for capacitance, s for time, J for energy, integer requests/groups/events, and USD upper estimates. `summed_wall_s` adds episode durations; it is not necessarily elapsed campaign wall time. F2/F3 missing ablations are explicitly marked NOT_EVALUATED, never zero improvement. `new_scientific_executions` in historical inputs describes original work; phase5 reproduction adds zero.
