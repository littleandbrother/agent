# Evidence-gated research roadmap

This roadmap replaces the previous tendency to treat the world, Studio,
evidence system, Harness, and evolution machinery as parallel contributions.
They now serve one sequence from experiments to future expertise.

The machine-readable authority is
[`project/ROADMAP.yaml`](../../project/ROADMAP.yaml). Status is earned only from
feature receipts, tests, manifests, and sealed artifacts; no hand-maintained
completion percentage is authoritative.

## What remains frozen

- A-001 remains the reproducible F1-simplified Rotary-TENG reference.
- B0-000 remains the semantic truth-table suite for PASS, overvoltage,
  brownout, and wrong diagnosis.
- Their hashes and claim boundaries do not change under this reframing.
- Legacy prototypes and old atlases remain historical inputs until reproduced
  in this repository under a current Feature.

## Milestone sequence

| Milestone | Visible outcome | Scientific meaning | Current state |
| --- | --- | --- | --- |
| A1 Visible Current World | A-001 and repository coverage appear in one truthful Studio | implemented evidence is observable without invented capability | complete |
| A2 Complete Coupled Mission | five coupled controls with integer inference and receiver events | energy and information close in a synthetic computational task | complete in declared scope |
| B1 General Agent Closed Loop | one fixed general Agent experiments and submits under controlled execution | finite-catalogue pilot works; not full long horizon | complete in bounded computational scope |
| B2 First Knowledge Transfer | one qualified programmatic knowledge object helps a new task without source conversation | experience exceeds the originating episode | in progress; B2-003 mechanical and counterexample development |
| C1 Continual Learning | knowledge is added, reused, rejected, restricted, superseded, and revised across campaigns | future capability changes over time | blocked by B2 |
| C2 Cross-Reality Confirmation | benefit and scope are tested on a new device/session, independent implementation, hardware condition, or source | gains are not confined to self-generated reality | blocked by C1 |

The evidence-gated count is currently **3 of 6**. B1 counts only its finite
real-model pilot. B2 compiler/capsule software is not a completed learning result.
The guided capsule passed explanation tests but failed its whole-use gate; the
rejection and unsolved task are retained. See `docs/PROGRESS.md` and validation
receipts for current scope. C1 lifecycle primitives exist, not a continual study.

The only active feature is B2-003. New deployment scenes, extra old-protocol paid
trials, model replacement and open-ended harness evolution are paused. Formal
split, budget, thresholds, baselines and statistical decisions stay owner-owned;
`studies/b2-003/protocol-draft.json` is not a launch authorization.
Concrete decisions for review are in `studies/b2-003/OWNER-REVIEW-PROPOSAL.md`.
Independent workflow use controls now reuse sealed public evidence; simple
fixed ordering already beats the old enumeration baseline, so future knowledge
claims must account for that classical control rather than attributing all
probe reductions to learning. No new formal workflow qualification is claimed.

## A1 — Visible Current World

The first active development target is not a decorative 3D scene. It is a
trace-faithful Study Atlas and replay surface for what the repository really
contains today.

It must show:

- A-001 component topology, thresholds, revisions, events, and synchronized
  channels;
- B0 expected projections and failure-certainty levels;
- prediction, simulation, and evidence provenance;
- repository Feature gates and evidence levels;
- unimplemented PMIC, real MCU inference, receiver, Agent, knowledge, hidden
  qualification, and hardware layers as grey explicit absences.

Every visible value or verdict comes from a channel, manifest, or receipt. The
frontend never recomputes scientific truth. A copied sealed run must replay
without an online scientific service.

## A2 — Complete Coupled Mission

A2 freezes only contracts required by one complete experiment, then implements
one Rotary-TENG reference path:

```text
environment -> load-dependent harvester -> power/storage/PMIC
-> sleep/sense/infer/TX load -> actual request prediction
-> receiver-side delivery -> mission outcome
```

Fidelity is recorded per component. A global label cannot hide a mixture of
analytic source, circuit simulation, measured load, integer inference, and
simplified radio. Reference anchors must include passing, failing, and boundary
cases; internal agreement between one model and itself is insufficient.

## B1 — General Agent Closed Loop

B1 connects one general coding Agent only after the no-Agent reference passes.
DSH is a thin and pinned control-plane adapter. The runtime retains journals,
artifacts, budgets, recovery, and evidence identity.

The episode must distinguish design, world-model, and workflow revisions. Crash
recovery guarantees at most one officially committed and billed effect per
idempotency key, not magical exactly-once execution of external providers.

## B2 — First Knowledge Transfer

B2 is the earliest scientific decision point for EpiDesign. One candidate
knowledge object must:

1. explain held-out observations;
2. run outside its originating session;
3. improve a new task under equal historical information;
4. survive a transplant test;
5. show a selective removal effect;
6. report acquisition, qualification, execution, and solve cost;
7. identify at least one known limit or rejected use.

It is compared with raw-history retrieval, text memory extracted from the same
history, and a classical identification or surrogate-optimization baseline.
The general Agent baselines may write code and build tools; they are not
artificially weakened.

If B2 shows no gain, the project stops scaling and diagnoses task difficulty,
knowledge scope, invocation cost, and baseline saturation.

## C1 — Continual Learning

C1 extends one transfer to counterbalanced campaigns. Candidate selection and
sealed final confirmation remain disjoint. The main mechanism analysis crosses
fixed/learned world models with fixed/learned design workflows so their effects
are not conflated.

Campaigns retain failures, invalid revisions, no-update cases, infeasible
tasks, regressions, and genuine scientific replications. Executor-equivalent
retries remain a separate process metric.

## C2 — Cross-Reality Confirmation

C2 introduces independent information: another implementation, unseen
device/session, hardware condition, or a second energy source. It tests both
in-domain transfer and out-of-domain scope recognition. Claims remain limited
to the reference actually observed.

## Paper evidence

The study is organized around four questions:

1. Is the world coupled and independently anchored enough for credible design?
2. Does executable knowledge improve future design over fair alternatives?
3. Is improvement due to world knowledge, workflow, or their interaction?
4. Can knowledge transfer, be removed, recognize its limits, be falsified, and
   be revised?

The paper's strongest figure should show the full lineage from a failed
prediction through discriminating experiments and knowledge qualification to a
measured benefit on a future task—not merely a polished system diagram.
