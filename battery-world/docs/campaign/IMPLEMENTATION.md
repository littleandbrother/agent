## Safety and reproducibility

The trusted controller holds the provider credential, never the participant.
The credential is private/ignored, 0600 inside a 0700 directory. It is absent
from source, model messages, reports and UI. No paid call occurs in `init.sh`,
unit tests, browser loads or UI buttons.

Integer micro-CNY reservations precede dispatch. Limits: user CNY 2/trial and
strictly below CNY 20 total; engineering CNY 19, 120 calls, 600,000 tokens and
3600 active launch seconds. Unknown calls retain their reservation and cannot
implicitly retry. Cached calls require the exact request hash. Process-death
tests cover reservation and settlement. Completed campaign replay reproduced
the report with zero added paid calls.

Model-authored Python runs under macOS Seatbelt with a clean environment,
private read/network/external write/fork denial and CPU/output limits. These
are tested local research isolation properties, not an exploit-proof VM claim.
Every arm receives identical raw history and can run Python. Final conditions
are evaluated only after learning freezes; qualification is development feedback.

The Studio shows costs, actual decision summaries/actions, tool facts, code,
scope/dual qualification failures and selected-submission 3D/voltage replay.
Private chain of thought is not copied. The single offline HTML is compressed
without discarding samples and has no CDN dependencies.
