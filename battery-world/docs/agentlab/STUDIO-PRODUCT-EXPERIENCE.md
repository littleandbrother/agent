# Studio 项目使用与交付体验 · BFA-032

日期：2026-10-01。应用：<http://127.0.0.1:8768/>。

本轮使用已安装的 apple-hig 普通指导模式。HIG 关于材质的原句是 “Don’t use Liquid Glass in the content layer.” 本项目采用网页实现：玻璃限于顶部工具栏、菜单和模型悬浮控件；工程图、波形、文件与交付清单保持实底。具体像素、动画时长与排版为项目选择，不声称是 Apple 强制数值。

## 用户路径

1. 项目侧栏保留已有文件夹、会话、恢复、移动、改名和宽度调整。新增项目搜索。Studio/Lab 切换放到侧栏底部。
2. 同一项目在顶部切换「对话｜产品｜交付」。对话草稿仍由现有会话存储保存，切换视图不会发送内容。
3. 产品首先呈现所选范围、真实结论与工程预览，再按机械、电路、固件、系统查看产物。相同类别的预览使用文件名区分。
4. 有装配的项目默认显示装配适用成果。独立归档案例和会话全部历史必须显式选择。没有装配时展示独立记录，不制造当前采用版。
5. 交付成为常驻视图：选择用途 → 检查文件 → 生成固定快照 → 下载。可以直接预览可读取的技术报告。

## 数据和范围

继续使用现有后端和产品记录库，没有创建另一套产品事实。StudioModel 与 StudioDelivery 分别在展示和导出边界裁剪范围。装配只包含 applicability=current/reused 的文件；结果内部文件和预览也同步裁剪，避免历史附件穿透范围。原有运行状态、设计判断、仿真范围与实物验证标志保持不变。

自动生成的长提示词标题仅在已读取首条用户消息并确认匹配时，允许以已归档产品名作侧栏显示标签；原始会话名保留，用户改名优先。显示缓存只存在浏览器会话中。

交付提供三种不同内容：

| 用途 | 实际内容 |
| --- | --- |
| 结果概要 | 可离线阅读的 HTML + JSON 清单，包含结论、指标、范围和文件可用性，不附大文件 |
| 技术报告 | 已归档报告 PDF、同目录 TeX/图像资料，以及可解析的相对引用依赖；不顺带打包无关原生工程 |
| 工程资料包 | 当前所选范围的全部可读取原生文件、数据、源码和计算记录 |

报告依赖解析不会执行 TeX，不读取注册清单外的路径。动态宏引用、未归档依赖和过大源文件明确列为提示；导出不等同本地复编成功。报告目录与所有 literal include/input/includegraphics/includepdf/bibliography 引用保留原相对路径。超过注册范围的引用不会自动补造。

交付继续校验 owner、快照、文件哈希、相对路径、ZIP 清单和读回。新增 v2 离线说明，不破坏旧 v1 交付包读回。选择其他项目、版本或范围后，旧请求不能写回新页面。打包期间用途控件锁定，防止选择和实际文件不一致。

## 视觉与交互

系统字体、统一语义颜色、较宽行距、清晰字号层次、灰白内容与克制蓝色操作。去除输入框、交付正文的玻璃以及鼠标跟随亮斑。项目标签采用短位移过渡；弹层和页面使用短淡入；启用减少动态效果时停用动画。

响应布局按实际主内容宽度切换，兼容用户拖宽侧栏。窄主栏将工程结果列表改为横向选项、交付改为单列；左栏保留可展开入口。保留键盘焦点，触摸环境显示原本悬停的操作；支持系统深色、提高对比度、减少透明度以及无 backdrop-filter 的实底回退。
