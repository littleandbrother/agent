# BFA-026 产品成果工作区

日期：2026-09-29。状态：平台交互与数据链路已完成，已加载本机 8768 服务；不表示产品、实物或论文方法验收完成。

## 使用路径

选择左侧任务 → 产品 → 当前成果。原来的设计图保留为第四个页签，不再占用默认主视图。

- **当前成果**：本轮目标阶段、五层交付状态；机械与结构、电路与 PCB、固件与模型、系统与交付；每种工程优先展示最新可用运行。可直接旋转装配 / STEP 派生网格、读取求解器曲线、查看固件资源和提交时源码。
- **过程与比较**：完整运行历史，包括失败与未绑定记录；同类运行的原始指标、实际装配输入、接口、条件和源码哈希变化。不根据时间顺序虚构修改原因。未登记原因时明确显示缺失。
- **原始工程**：按文件名查找全部源码、原生文件、数据和报告。生成版本与适用关系分开显示；历史、失败和尚未验收的文件仍可打开或下载。
- **设计图**：保留既有节点、连线和事件回放；接收同一后端成果清单。它没有新的产品判定权。
- **具体 Trace**：每个运行的入口按 job ID 定位控制台记录；返回产品恢复原视图、领域、运行和滚动位置。
- **新结果提示**：后台更新不覆盖正在阅读的源码和历史比较；点击更新后才刷新当前成果快照。

任务页的模型与文件侧栏改为指向产品主入口，减少多套文件画廊。参考工程单独选择，保留 COMSOL、LTspice 图表、结构模型和原始资料，不抵扣当前任务的交付。

## 后端与数据库

原系统已有 Python 后端和 SQLite。本次在同一后端增加 `ProductResults`，数据库新增可重建的 `product_result_index`，不创建另一套独立产品状态或数据库服务。

```
现有 engineering_jobs / assembly_revisions / assembly_files / binding / verdict
    → 产品结果索引（owner + result_id；仅元数据）
    → 版本适用性和原文件哈希检查
    → /api/results
    → 产品页面、设计图、完整工程包
```

索引由任务读取时幂等更新，保留 source_sha256；删除索引行可从原记录重建，不能修改其余源表。原始字节仍在不可变工程目录和已发布文件目录中；无需复制大型 COMSOL 文件到数据库。`CREATE TABLE/INDEX IF NOT EXISTS` 兼容现有 state。

接口沿用当前认证，普通参与者被固定到自身 owner，只有操作者可选择其他任务：

| 接口 | 内容 |
|---|---|
| GET `/api/results?session=&revision=` | 结果、领域、原始输入、量值、文件、适用性、完整性、缺口及快照 SHA |
| GET `/api/results/file?session=&id=` | 精确已登记文件；校验 owner、路径与哈希 |
| GET `/api/results/source?session=&result=&name=` | 提交时不可变源码；保留工程内相对路径 |
| GET `/api/results/series?session=&id=` | 原始 RAW / 数值 CSV / TSV 的有限绘图投影 |
| POST `/api/deliverables`, action=package | 按给定 revision、snapshot_sha256 打包同一份清单 |

数据库是结果索引，原验收器仍决定结论。某个本地工具成功，不能让页面给完整产品打勾。

## 版本、完整性和原生结果

创建版本永不改写。根据既有声明的输入范围检查 `current / reused / stale / unbound / future`：CAD 使用几何与接口；固件使用接口与能源；产品模型的几何、显示、能量文件分别使用相关输入。未知任务保持保守范围。这是静态声明的复用规则，不是学得的因果关系，也不证明自由 CAD 与装配 JSON 在物理上完全一致。

历史版本不套用当前 verdict 或当前缺口，后续生成的文件不当作历史证据。文件哈希不符、缺失、符号链接或未下载的云端占位均显示不可用；索引不能绕过原文件读取权限。原生 CAD 的独立读回额外从确切 STEP 派生网格，记录 STEP SHA、mm 单位与三角面，最多 20 万面。单实体预览不冒充完整装配，旧 CAD 未生成网格时说明原因并保留下载。

SPICE 图直接读取 ngspice 实数 RAW（ASCII / binary）；坐标单位来自变量头，显示采样数和源哈希。超过 1000 点等间隔抽样并明确提示，极值判断仍用原始全量数据。复数 RAW、非数值表和超过 32 MB 的预览保留下载，不制造替代曲线。固件显示固定目标的 ELF 资源读回、源码路径和文件内容；不展示虚构板上运行状态。Markdown 为转义后的正文 / 标题 / 表格 / 列表 / 代码阅读器，PDF 允许同源沙箱嵌入；尚不是完整排版、公式或专业 CAD 编辑器。

缺口分开显示缺文件、输入变化、检查失败、尚无独立验收；运行中的作业、外部操作与待核对状态单列。没有实现的专项验收器保持未完成，不通过重复运行或前端着色来消除。

## 完整工程包

包内 `成果清单.json` 与页面快照相同，保留旧 `验收.json` 和 `交付标准.json`。全部列出的原文件按专业放入 `成果/<domain>/<current|history|failed>/...`，包括未额外发布的工程 Job 产物。多文件源码仍保存在原结构的 source ZIP 中。不会把导出的包再次收入下一次导出。
