# 长会话上下文超限修复 — 2026-09-23

本次修复 `MODEL_CONTEXT_BYTE_LIMIT`：这是本机请求预检错误，不是 DeepSeek 账户余额不足，也不是累计 token 用尽。服务已更新到 8768；没有提高预算、删除会话或自动重跑产品任务。

## 根因与复现

原投影器删除完整的旧工具交换及较早的助手文字，但完整保留系统提示词、最近两次工具交换和最近四段助手文字。旧产品会话的一条系统记录约 116 KB，其中产品状态 JSON 约 80 KB，带入了大量工程历史。大块状态本应是可按需读取的数据，却和系统规则一起保留。最近的大工具返回也没有容量兜底。

使用当前 Pi SDK 将实际会话日志转回请求格式，回放 `pi-chat-cf37636f82c771a4`：原始 364,883 字节，关闭新归档步骤时精简后仍为 129,790 字节，超过本地 128,000 字节门限；启用归档后为 48,724 字节。此为离线请求重建，不冒称截获了旧 HTTP 请求。

另一个长会话 `pi-chat-7bbf6862d7109e25` 的 1,627,562 字节请求可按原有策略降到 103,407 字节，新归档步骤无需介入。

## 修改内容

- 在容量不足时，把明确标记的启动产品状态 JSON、已完整返回的工具结果、大段助手文字保存到本会话 `context-records/<sha256>.json`，请求中保留路径、哈希、字节数及标明不完整的首尾预览。
- 归档是确定性的 JSON 内容寻址文件。已有文件必须逐字节一致；路径穿越、符号链接和内容冲突被拒绝。Agent 可以用已有读文件/Python 工具选择所需字段，无需重做实验。
- 用户消息、系统工程规则、工具调用 ID 和参数、未完整返回的并行工具交换保持原样。原始 Pi 会话与 Trace 不改写。
- 仍不可容纳的必需指令明确拒绝，在创建付费请求之前写入 `model_context_rejected` 审计；不把此错误记成用量未知。
- 控制台 Trace 显示归档数量及来源；时间线可查看新产生的容量预检拒绝，拒绝不计入模型请求数或费用。
