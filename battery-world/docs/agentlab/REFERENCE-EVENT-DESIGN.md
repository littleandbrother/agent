### 机电、电路与负载瞬态

新增 `bf_engineering` 的 `event-transient` 引擎，实际调用本机 ngspice。输入为参与者工作区中的 JSON；提交时冻结规格及其哈希，执行文件与输出归档。

求解包含单模态位移/速度、压电端口、双向机电反馈、二极管桥、储能、静态损耗、迟滞上电/掉电和多个固件阶段负载。可选择声明的力轨迹，或有明确方向与适用条件的磁偶极势模型。电负载变化会反馈到机械响应。

输出包括真实网表、日志、完整 CSV、时间线、启动/中断/完成时刻、能量账目和粗细步长对照。检查求解是否到达终点，避免 ngspice 提前停止但退出码为 0 被当作成功。

适用边界：这是压电降阶模型，**不能验证线圈电磁发电机**；力输入模型不能验证磁拨动机构。行为电源模型不是原厂 PMIC 模型；模拟发送不是真实接收。磁偶极远场筛查也不能取代磁力实测或有限元校准。最终审查还纠正了势函数的方向文字：当前负势能模型对应垂直运动平面的反平行磁矩（吸引），不是同向磁矩；此前两次磁分支本来就未通过，不追溯修改其记录。通式来源：[URI 磁偶极相互作用讲义](https://penrose.uri.edu/Gerhard/PHY331N/wlex130.pdf)。

### 真实测量接口与受控分支

- 操作者可导入负载 CSV，必须绑定本会话实际构建的 BIN 哈希。保存仪器、硬件、采集时间、原始 CSV 和按阶段积分结果。
- 参与者不能自行把 JSON 的 `origin` 改成 `measured` 获得测量资格。仿真负载阶段、固件哈希、电压与导入记录不匹配时拒绝。
- 导入仅证明记录和绑定一致，采集来源仍由操作者说明；不会自动证明烧录、无线接收或整机验证。
- 接收事件评估按记录的动作 ID、时刻和接收记录检查超时、缺失、重复和无匹配事件。
- `scripts/run_event_branches.py` 可冻结 D、D+a、D+b、D+a+b 四份规格，保持动作、初始储能、要求和数值设置一致，全部重新求解。校准运行已执行；它只验证分支执行器，不构成方法收益或因果泛化结论。

### 为什么整机验收不通过

1. Pi 初选电磁线圈方案，却调用压电模型。独立审查明确指出失配。后来改为压电力输入候选，其计算通过仍不能证明磁拨动机构成立。
2. 初次磁模型远场适用范围不满足；另一轮 COMSOL 小变形假设失败。记录保留，不能用另外的通过算例替代这些失败。
3. 最后一次力输入压电候选通过该模型的数值检查，但机械尺寸、力/行程、材料与耦合参数、真实电源和固件还没有形成同一版本的完整物理依据。
4. 原生 CAD/Blender 生成成功不证明磁铁固定、压电层、线圈/磁路、动作运动学和原生 PCB 已完成。
5. 立创桥未连接，未生成本开关的原生原理图、PCB、ERC/DRC 和制造包。
6. 已编译的 STM32 BIN 是现有按键/LED 基线，**不是这份无线发射程序**。Pi 的无线逻辑只有主机桩构建，缺真实 SPI 驱动、启动/链接集成、掉电后的事件身份保存和板级测试。
7. 没有目标板、ST-Link、同步电流测量或真实接收证据。载荷仍是估计，不能拿编译通过替代功耗/时延测量。

验收记录明确为 `NOT_QUALIFIED`，不是通过。

## 4. 独立代码检查与修订

Pi 的原始主机测试通过，但独立负控发现：不同设备相同计数相互干扰、UINT32_MAX 作为哨兵导致重复接收、非法事件码被接受。原测试还包含恒真断言，发送等待没有落实超时。

原始输出保持不变。`firmware-reviewed/` 是明确标注“协调者修订”的独立副本：修复设备计数隔离、边界计数、事件校验、恒真测试与有限轮询。原测试、三项独立负控和无线永不完成的超时测试通过。仍只是便携逻辑，未补称真实无线驱动或可烧录整机固件。

## 6. 余下工作和推进条件

下一轮应针对这份失败记录修复，不再增加展示壳层：

1. **冻结同一件产品**：让机械运动学、换能方式、材料/几何、采能电路、负载、固件和通信协议指向同一设计。引用需落实到适用条件和参数，而非只在说明中列链接。
2. **补物理模型依据**：磁力随位移/间隙的标定或有限元；复合梁模态、阻尼、压电耦合；关键参数不再任意假设。行为 PMIC 与真实器件冷启动、漏电、峰值负载及保护逐项核对。
3. **完成原生电路**：连接立创独立工程后，在当前 BOM/引脚/尺寸下生成和检查原理图与 PCB，回读实际网表。没有接口连接不能伪造原生通过。
4. **完成目标固件**：把便携协议逻辑接到实际主控/无线器件的驱动，完成真正的无线 BIN、可复现构建与接口测试。验证完全掉电后的事件计数策略；测量启动、发送、NVM 与重试负载。
5. **物理闭环**：目标板、烧录器和仪器到位后，同步动作、供能、固件标记与接收端事件。真实波形通过测量入口绑定；独立核对调试和测量线路是否引入额外能量。
6. **论文实验**：先取得合格完整设计及自然失败，再冻结开放检索和等资料两类协议。A 的联合修复、B 的复用/重验、C 的 Harness 修改须分别研究；本轮四分支夹具和代码修订不替代正式论文结果。
