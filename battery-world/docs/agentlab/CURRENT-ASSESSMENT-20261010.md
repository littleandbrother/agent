## 系统能力

已实现短核心提示词、冻结技能目录、严格加载、资源哈希、活动技能上下文保护、原 owner 恢复、不可变作业回执与独立检查。目录记录 21 项技能/4 组插件；十篇数据库中实际激活 8 个技能 ID、63 条记录。已安装、实际加载、正确使用是三个状态。十篇尚无完整 EasyEDA 专业流程通过的证据。

可执行工具覆盖参数化 CadQuery/STEP、ngspice、STM32L031/STM32L432、nRF52832 裸机与 SDK/S132。P04 的问题是集成和执行方法，不是缺编译器；ATtiny25 不在当前原生目标适配中。MCP、typed CLI 与本地工程服务是不同接口实现，不替代专业知识和验收。

Pi 已证明能在具体反例后修复部分工程。静态几何不证明机构运动；编译不证明 RF、实际功耗或硬件启动；代理电源模型不证明论文整机；Three.js 五个工作间是能力区域，不是五个独立 Agent。

## 主要系统卡点

1. 队列的 CHECKS_COMPLETE 来自局部阶段 PASS，未自动由核心功能门驱动续接。
2. 具体错误关闭与更广功能未验收没有充分分离。P08 旧分析问题仍 OPEN，不应继续重复修同一问题，也不能将核心模型改成 PASS。
3. P02 候选/主版本、P04 portable C/目标 HEX 缺少明确依赖收口；文件哈希不能代替版本接受决策。
4. 若干论文停留在局部代理模型，缺少机械输入、源适用性和真实通信的关联。
5. 主动检查仍较依赖 Codex 教师反馈；Pi 写源码不等于全过程独立判断。

## 方法实验与论文结论

M1 未测得收益而拒绝。M2 的清单、几何为 PASS/PASS，异步固件为 FAIL/PASS；父三项成本 $0.1647339，M2 $0.2635452，改进器另 $0.0573045。M2 仅局部资格，未广泛生产采用，无统计迁移或总成本收益；两个候选都从 M0 出发，没有递归后代链，也没有权重训练。

可支持的研究结论是：有可追溯多专业产物、独立反例和 Pi 反馈修复；一项局部方法候选恢复了父方法失败。不能宣称十篇全产品自主复现、稳定跨论文学习、总体降本或 RSI。十篇已用于开发，不能回溯称为保留测试；未来独立迁移需新任务。

Codex 负责公共设施、公开反馈、独立复查与封存；参与者工程源码修改归于 Pi。教师提供的问题方向、复制的复查输入和公共工具修复分别记录，不计为 Pi 自主发现。
