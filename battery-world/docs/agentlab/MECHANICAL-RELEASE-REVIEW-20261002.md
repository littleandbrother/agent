## 3. 当前装置与论文的差异比电容更根本

当前 COMSOL 降阶梁：刚度 87.20 N/m、等效质量 8.72 g、压电电容 17.23 nF；参考仿真论文的另一套器件约为 605.92 N/m、20.12 g、40.22 nF。当前磁体为 10 mm/20 mm 立方体、名义 Br 1.25 T；论文尺寸、位置、Br 及运动条件不同。它们不能只替换其中一个参数后宣称完成论文复现。

当前构型为同向磁化、吸引式加载；后两篇参考中的排斥式磁拨动提供了值得研究的另一种加载/释放关系。当前计算从静态预弯平衡启动，没有显式记录此前关门加载的全部输入功。但“从预弯开始”本身不能证明没有释放或没有振动；必须读取实际轨迹。

当前插值力表的 261 个采样角度各找到一个稳定平衡。这仅是有限域/有限采样的检查，不是全域无失稳证明。现有波形确有振动，不能把它描述成完全准静态过程。

## 4. 基线能量去了哪里

冻结基线原生账本：

| 项目 | µJ |
|---|---:|
| 起点机械/压电储能 | 758.637 |
| 磁力对梁的净做功 | −662.893 |
| 机械阻尼耗散 | 91.754 |
| 进入 PMIC 端口的能量 | 3.991 |

磁力净功约为初始储能的 −87.38%，阻尼约 12.09%，PMIC 端口约 0.526%。机械/压电端口能量残差约 1.75×10⁻⁶。这里的负功表示能量离开所定义的梁子系统，可能进入磁场/驱动侧；不能直接当成实测“返还到门的功”，更不能据此计算完整门动作效率。加密 PMIC 内部损耗也未独立闭合。

独立 1 MΩ 电阻控制中，现有旋转路径提取约 52.0 µJ，理想瞬时撤力约 199.4 µJ。后者只是释放方式诊断，未实现可制造结构，也不是经过证明的全局能量上界。静止门/静态平衡控制没有凭空产生可观电能。

因此，当前值得优先优化的是加载与释放路径及电提取时机，而不是继续仅扫描电容。

## 5. 已执行的真实结构对照

驱动磁体绕部件局部 z 轴翻转 180°；部件局部磁化保持 +x，装配旋转后在原参考坐标中为 −x。对均匀硬磁化、回复磁导率为 1 的模型，此变化对应磁力表反号。方形磁体翻转前后外形相同，所以 STEP 必须与磁极方向/装配说明一起交付，不能仅靠几何文件证明极性改变。

实际产物包括 STEP、输入装配、磁化方向说明、反向力表、C 在环文件、原生 `.cir/.raw/.log`、供电与程序波形、接收结果和哈希回执。CAD 回读 22 个有效实体，无静态碰撞；不等于完整动态干涉或物理磁场确认。

| 结果 | 冻结基线 | 翻转驱动磁体 |
|---|---:|---:|
| 起点机械/压电储能 µJ | 758.64 | 434.31 |
| 磁力对梁净功 µJ | −662.89 | +178.85 |
| 机械阻尼 µJ | 91.75 | 596.92 |
| PMIC 端口能量 µJ | 3.99 | 16.25 |
| 输入储能电压峰值 V | 0.146 | 0.434 |
| 梁尖绝对位移峰值 mm | 4.54 | 7.05 |
| 冷启动 / 完整 TX / 接收事件 | 否 / 0 / 0 | 否 / 0 / 0 |

端口能量约为原来的 4.07 倍，但两者的初始机械储能与磁力做功不同，不能称为“效率提高 4 倍”。翻转后阻尼仍消耗了大部分进入梁的能量，电源也仍未启动。该变化证明一个真实装配自由度能贯穿原生产物与联合求解，尚未证明有效产品或充分的模型工作域。

另有关门—保持—开门的 1 MΩ 诊断：同向约 103.8 µJ、翻转约 426.8 µJ。其时间过程不同于冻结 4 秒任务，且没有 PMIC，因此不能合并进上述表格计算任务成功率。

## 6. 审查也发现了 Pi 和辅助代码的错误

Pi 首份报告把 `sqrt(2×714.6e-6/605.92)×1000` 算成 48.6 mm，正确算术结果为约 1.5358 mm，两者比值约 31.64。其“40–50 mm 振幅、6 倍振幅差、36 倍能量差、应扩大 ±8 mm 域”的建议被拒绝，原文和纠错文件都保留。

新增 `bf_reference.calculate` 用带单位字段计算，绑定已获取原文 ID、文件哈希与定位信息；不执行任意表达式。它明确返回 `design_admission=false` 和 `source_values_verified=false`：只核算算术，不自动验证参数抄录、模型适用性或理论前提。

Pi 纠错文件仍把错误倍数写成“316 倍”，并把反算量称作一般的机械能下界。这些说法也未获采纳。714.6 µJ 是特定电路的电储能，把它代入弹簧公式只能得到一个有条件的等效位移；在驱动侧/磁场继续做功时，不能一般性地当成初始位移下界，更不能据它重设模型域。纠错文件不是独立验收结论。

辅助控制代码首版也曾把完整关开门流程错误地施加成关门角度的力。端点检查发现错误，旧目录已标排除，新增“返回远磁体平衡”回归测试后重新运行。结构探针 v2 的磁化坐标文字同时用了局部 −x 与 180°旋转，存在重复翻转的标注歧义；计算使用的反号力表没有变。v3 修正坐标说明，新增旋转一致性测试，重新生成 CAD 并再执行一次原生求解，数值与 v2 一致。v2 保留历史，不作为最终装配说明。

这种核查必须同时约束 Agent 和研究脚本，不能只审查 Agent 的自然语言。

## 8. 下一轮实施顺序与准入规则

1. **完整机械输入**：在共同坐标系保存驱动位姿、磁化方向、梁位移、完整磁场能/驱动侧广义力；对关门加载、临界附近、开门释放分段核算。不能用 `∫F梁·dq` 代替全部开门输入。
2. **新结构工作域确认**：先检查翻转构型实际经过的门角/位移点和高梯度区，独立 FEM 与网格细化；检查间隙、碰撞、梁应变以及时步敏感性。未确认点返回模型未定，不能记为器件失败。
3. **只开放一个明确结构自由度**：先开放磁化方向/安装姿态及其有界路径。协议另起 v2，固定门动作、初始电能、负载与数值规则；实际 CAD、磁化属性、力表与评价必须同版本。旧 v1 任务保持封存。
4. **再比较电提取结构**：依据能量账本决定是否比较桥式 PMIC 与有原文依据的同步提取/负载门控。每种电路都有实际可执行工程和状态控制，不能直接借用另一拓扑的论文效率常数。
5. **最后运行 Pi 结构迭代**：Pi 先提交带原文位置、单位、同异条件和必要检查的假设表，再提出候选。冻结任务条件不能通过改阻尼、负载电流或接收要求获得成功。首次只做少量轨迹，保存检索失败、被拒绝建议和全部运行。

本轮得到的是可执行的下一步依据，而不是“已经完成自主产品设计”。优先完成驱动路径和物理工作域确认，再将探针接入 Pi 的正式结构合同。
