# 八页结构

| 页 | 主题 | 核心图 |
|---|---|---|
| 1 | 整机方案与交付结论 | 实际模块组成、能量与信息路径 |
| 2 | CAD 尺寸与安装接口 | 三视图、等轴图、尺寸和安装位置 |
| 3 | 机械结构与装配 | 爆炸图、编号零件、运动与固定关系 |
| 4 | 电气架构与 PCB | 功能结构、板卡正反面与接口 |
| 5 | 原理图与关键回路 | 全图及关键回路局部图 |
| 6 | 固件状态与时序 | 状态转换、任务事件与配置 |
| 7 | 供能、功耗与储能 | 声明工况、真实波形、能量账与事件放大 |
| 8 | 需求验收与交付目录 | 当前检查矩阵、剩余问题、文件与交接 |

版式：A4 横版，白底、浅蓝分区、深蓝标题；中文为主。标题、状态、坐标与单位使用真实文字；图标用矢量绘制。版面按数据量调整。
