# 连续设计与组织方式实验

1. 原压电主会话切换到已资格化反馈配置，固定零储能、20秒、至少3帧。沿用工程与账本，连续两轮由Pi选择真实修改、执行、独立验收、决定及同版交付。
2. 两个资料任务做直接检索/临时资料工作者配对比较，核对数值、单位、工况、来源、主会话消费与总费用。
3. 四种组织在四个固定任务上比较：单主设计者、按需临时委派、固定专业分工、按证据扩大共同范围。相同模型、资料、初态、工具与判据；前两个任务为验证集，后两个封存为最终测试，禁止用最终测试反馈选择方法。

固定有限实验清单；每次候选、执行、报告、费用、人工介入均追踪。初始允许设计范围与每次试验动作数在启动前封存。失败结果保留。Baseline、原十会话、Demo与历史费用不变，输入未变的成功仿真复用。
