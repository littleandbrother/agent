## 开发中关闭的具体问题

1. LTspice 的机械等效电感隐含串联电阻带来了额外阻尼。网表显式设置 `Rser=0`，阻尼由独立元件定义，机电能量残差降至约 `1.27e-6`。
2. 原生 RAW 的合成零时刻记录与声明初态不同。检查器核对首个实际积分点及初始储能，保留完整波形。
3. 负载转换不得早于程序决定。PWL 转换从当前事件时刻开始，加入前因性回归。
4. 超时与解析失败分别保存；未知执行不重新派发，已确认的失败保留原回执。
5. `BF_OFF` 由供电监控器生成，上电程序只允许选择待机、采样和发送，防止用未供电漏电电流替代正常待机电流。

旧探测与校准记录继续保留。旧参考适配器、原候选、原 Pi owner 和原 Demo 资产保持原状。本轮未恢复 Pi，未启动原 Web 服务，未提交或推送 Git。
