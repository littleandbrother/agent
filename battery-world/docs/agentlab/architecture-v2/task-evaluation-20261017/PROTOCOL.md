# BFA-039 执行与实验协议 v1

冻结时间：2026-10-17；正式输出前保存输入及代码摘要。

1. 48 条简短请求覆盖六种意图、单模块/联合/整链、缺条件及冲突。每条独立模型请求，固定模型与任务说明。先冻结参考标签，再生成分类、任务定义和方案。24 条开发、24 条测试；失败原样保留。评价意图、领域覆盖、范围、缺项识别、无依据硬约束、定义完整性。
2. 沿用现有压电参考候选与 Pi owner。查证实际压电采能器件、源模型及执行条件，补充可执行设计与交付。固定外部服务要求，按变化范围重算。
3. 从十个原案例选择一例，独立 V2 任务引用原始工程与证据，完成定义、执行/复用、检查、判断、交付。原 owner、原文件和费用保留；此例属于已接触过的开发迁移案例。
4. 机制实验：储能建立时序、事件有效窗口、反馈负载三个机制，各使用独立参数任务的开发/选择/测试集合。先构造无 Agent 对照；固定任务判据和求解器，比较静态接口、丰富接口、固定精化及反例驱动精化。测错误放行、错误拒绝、覆盖率和观测成本。
5. 重放实验比较完整执行、旧轨迹固定回放及按依赖闭合的响应重放。记录政策排序、结果差异、重算范围和成本；模型生成方法修改仅读取开发集，验证集选型后冻结，在测试集一次评价。
6. 统计以任务/机制为单位；重复运行单独记录，不合并成新的任务。开销包括方法生成和验证。明确记录无收益、拒绝修改与适用域。
