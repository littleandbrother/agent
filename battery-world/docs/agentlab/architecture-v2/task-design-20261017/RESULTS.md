## 标准定义的实际效果

| 规则 | 实测结果 |
|---|---|
| 来源与角色独立 | 用户尺寸可以是硬约束或可改参考值；硬约束在提交入口执行 |
| 设计范围可执行 | 单位错误、未绑定约束、越界参数、未声明字段、固定文件变化被拒绝 |
| 接口有实际消费者 | 七组接口有统一目录；本参考链已接通机械—换能、换能—电源、电源—程序、数字接收四组 |
| 要求变化复用计算 | 同一 Pi R7 波形在 2.2 V 要求下通过、3.2 V 下供电失败；新增模型调用和求解均为 0 |
| 任务连续演化 | 阶段变化保留父树；旧专业工作区先重基；相同定义拒绝重复生成候选 |
| 恢复与交付 | UNKNOWN 先对账；完成但未登记的结果恢复登记；失败候选也可生成同版审查包 |

标准化回放检查 59 个实际内容对象，执行记录始终为 9 条。32 项标准化专项包含在 260 项 Repository 回归中，全部通过。

## BF 实际完成的两轮设计

固定场景：30 Hz、峰值加速度 4.905 m/s²、初始储能电压 2.5 V、20 秒、至少三次有效采样与接收。材料、转换效率及状态电流预先固定；Pi 可修改结构参数、储能容量与程序调度。

| 轮次 | Pi 的实际探索与选择 | 采用结果 |
|---|---|---|
| 第一轮 | 比较 33、28、22 µF；22 µF 供电失败。尝试调整端部质量使谐振接近输入频率，随后放弃位移余量较小的方案。最终选择原机械参数、47 µF、2/6/10/14 秒调度 | R6：4 帧有效接收，发送窗口最低 2.9309 V，五项名义检查通过 |
| 第二轮 | 从 R6 继续；两帧间隔 20 ms 的压力探针使 47 µF 第二帧降至 2.0599 V；68 µF 同条件为 2.6344 V。Pi 选择 68 µF，正式候选保留原调度 | R7：4 帧有效接收，标准发送窗口最低 3.1531 V，五项名义检查通过 |

两帧探针期间采能源保持输入。两版正式候选的平均负载均为 40.944 µW，转换后可用平均功率为 152.757 µW。R7 的改进集中在突发任务的电压余量。

机械参数与源模型相同时复用原求解。此次 Pi 产生 9 个系统候选，实际新增 8 次储能求解、1 次源求解，复用完整参考执行 1 次、源结果 7 次；重复派发相同输入的次数为 0。

## 下一批的具体工作

当前交付范围为**名义机电模型—储能—主机程序—数字接收**。参考转换效率、状态电流和材料参数已在任务中标明来源角色。
