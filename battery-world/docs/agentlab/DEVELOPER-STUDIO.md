# BF Agent 双模式工作台

入口：http://127.0.0.1:8768/ 。顶部「运行 / 开发者」切换共享所选运行，模式与模块保存在浏览器，所选运行在本标签页刷新后保留。

## 查看

- **Memory**：最后保存的任务状态、计划、假设、实验事实、公开经验和参与者备注。事实可以打开关联实验。
- **Harness**：冻结源码、编译与进程加载身份，P / U 源码，候选与父版本的差异。
- **RSI**：原有 P / U 谱系、生成过程、对照、拒绝及无修改记录。候选生成和校验通过都不表示能力提升或知识晋升。
- **Tools**：冻结配置与实际调用次数，输入、公开返回、错误及相关实验。旧轨迹没有逐次耗时；输入与返回按工具名和顺序关联。
- **Context**：任务输入、公开消息、费用和请求数。旧运行未记录组装提示词，明确标为未记录；新开发版本记录 Harness 生成的提示词，不声称覆盖 SDK 附加内容或每次完整请求。
- **Experiments**：本会话实验、快照、设计、策略、外部结果，以及到运行模式产物页的关联。

## 编辑与下一次运行

1. 在 Memory、Harness 或 Context 中点编辑；也可从下方新建配置，或复制已保存版本。
2. Memory 允许编辑假设、计划和手写备注。实验事实、待完成操作和已验证方案由运行记录提供。提示词编辑框写入求解/改进的附加指令；完整基础提示逻辑在 Harness 源码中可编辑。
3. 保存创建不可变版本，记录父版本、来源会话和代码差异；初始比较基线随新版本保存。未保存输入可从本机浏览器恢复。
4. 「校验构建」执行 TypeScript 编译、禁网沙箱入口检查，并绑定全部编译模块的散列。只校验接口和加载，不评价科学效果。
5. 「设为下一次运行」选择已校验版本；后续 UI 求解捕获该版本并再次校验源码、模块、应用、锁文件和世界身份。选择不会启动模型，旧运行及恢复使用原版本。可以恢复默认配置。

编辑器为本机操作者接口，参与者令牌不能访问。编译候选和版本分别位于 `bf-agent-workbench/developer/`；历史 sessions、participants、harnesses、studies 不被编辑器改写。仅已编译的 P / U 包被下一次求解加载；U 的附加提示词在该版本进入独立改进流程时使用，页面没有增加自动改进派发按钮。
