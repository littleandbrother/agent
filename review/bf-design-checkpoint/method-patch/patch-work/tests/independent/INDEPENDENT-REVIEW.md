The independent negative tests remain as regressions.

## Important limits and outstanding integration work

- This is an isolated offline implementation patch, not a runnable or scientifically qualified Pi deployment. No SDK session, live model, participant, scientific provider, native solver, design evaluation or promotion was run.
- Node's built-in TypeScript stripping exercises pure code but is not a project typecheck or a full package build. Six wiring checks explicitly inspect source, including one extracted exact resume guard; they do not replace end-to-end execution.
- Method record bookkeeping is verified; a qualified end-to-end dispatcher enforcing the full experimental opportunity budget has not been demonstrated. This version declares one revision round and two total opportunities per episode, and rejects resumes until a controller-owned checkpoint exists.
- A prospective `changed/tests/test_service.py` copy now migrates all four `RegistryService(...)` calls and the `run_probe.run(...)` call to explicit `strong_generic`. The original frozen test is untouched. This migration was source-inspected; the full legacy SDK suite remains unrun.
- R/Q distinctions are an inspectable prompt-first manipulation. Passing schema/trace checks does not establish that a participant follows the method, finds a feasible device, or improves performance. Current architecture proposals remain unsupported by the real provider.
