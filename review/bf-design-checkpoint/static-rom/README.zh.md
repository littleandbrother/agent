# BF 条件静态 ROM 与五状态广义力检查点

## 可以得出什么

本包保存 2026-10-01 已完成并独立审查的静态机械模型、广义磁力接口、原始数值和回执。它是新增的 PSI-5A4E 条件分支，不覆盖历史模型、世界身份、失败或先前交付，也不授权下一轮实验。

1. **透明静态梁模型。** 完美粘接、Euler–Bernoulli 梁和单项 Ritz 形状；刚度 87.162959 N/m，广义质量 8.693495 g，耦合系数 −0.255573 mC/m，固定形状电容 18.751974 nF。26 项生产方检查通过；独立 Hermite/Schur 方法复核 15 个量，最大相对差约 1.14×10⁻¹⁵。这个数值一致性不是 COMSOL 重建或物理校准。
2. **不能混用的电容。** 固定 Ritz 形状的 Cp 为 18.751974 nF；固定端点 q、允许被舍弃弯曲形状静态松弛后的 Cp 为 19.479399 nF。两者差 0.727426 nF，是不同的约束，不是可互换的记账方式。
3. **轴向补记。** α=1.377659×10⁻⁷ m/N，β=6.765579×10⁻⁹ m/V。固定 q、V 时的额外弹性储能含 βNV 项，可以为负；它不是损耗。实际力、电压和梯度范围尚未给出，因此没有“轴向响应可忽略”结论，也未决定第二轴向自由度是否足够或必需。
4. **五状态广义磁力。** 在 V=0 的指定 q-only 运动路径上，用同一互势能导数与力、质心力矩投影比较。5 个预定状态、4/6/10 阶积分，45 项能量导数检查通过；6→10 阶检查通过。最大虚功差 1.663832×10⁻⁹ N，最大 6→10 阶 Q 差 3.349964×10⁻¹⁰ N。26 项接口测试通过。
5. **记录补全不是独立样本。** 已保存 U(q+h)、U(q−h)、姿态及碰撞诊断；105 项同状态记录重放对比差为 0。独立审查只回读已保存数据，没有新增磁力状态、平衡求解或时间积分。磁体 OBB 分离只覆盖这些名义点及扰动点，不是整机或连续运动路径的安全证明。

## 符号变化如何理解

旧接口把 q 视为固定朝向的纯横向平移；新接口虽以磁体质心竖向位移归一化 q，却同时包含轴向位移与转动。因此比较的是不同的构型切向和广义力，不是 legacy 求力算法的数值错误。

- closed_zero：旧 Fz≈−0.315431 N，新 Fz 相同；新 Q≈−0.421222 N。差异来自轴向虚功约 −0.009662 N 与转动虚功约 −0.096129 N
- rotated_positive：旧 Fz≈−0.000533073 N，新 Q≈+0.000856892 N；转动力矩项约 +0.001193506 N。符号翻转说明旧 Fz 不能直接当作新 Q 使用

坐标注册已在源代码层面核对为右手变换；这不等于真实安装已测量或通过验收。

## 保留的限制

- PSI-5A4E 的典型常数是明确声明的新材料选择；原生 COMSOL 完整张量、实际等级/极性、胶层、电极质量、频散/公差与阻尼未知
- 静态截面消元基于 N=0；之后施加 Fx 和力矩会激发被舍弃的轴向/弯曲响应。现有投影在所选路径上功一致，但不等于任意载荷下的精确连续体解
- V≠0 会产生本 q-only 磁体姿态未包含的轴向平移。没有实际 F/V/梯度上界，不可声称误差可忽略或反馈收缩已成立
- 支撑范围是继承的计算范围，不是已证实的精度、安全或物理有效域
- 没有新动力学、力表扫描、平衡求解、原生供应商工具、硬件任务成功或正式 D/H、Agent/RSI 成功
