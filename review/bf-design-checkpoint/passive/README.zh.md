# 条件被动源／储能对照：47 µF 与 10 µF

## 结论与适用范围

在同一条件 PSI-5A4E 单坐标 q-only ROM、未标定 ζ=0.02 阻尼、理想全波桥＋固定 100 kΩ 串联电阻基准中，4 条重新封版并单独授权的轨迹均完成 4 s，冻结的数值检查及独立保留数据复核全部通过。

细步结果：47 µF 为 0.142364316 V、0.476288565 µJ；10 µF 为 0.591839203 V、1.751368211 µJ。电压比 4.157216，储能比 3.677116，储能差 +1.275079646 µJ。两项事先声明的“效果超过五倍观察到的粗／细差值”规则通过。它们是经验数值分辨率检查，不是统计置信区间、严格误差界或物理验证。

这一结果只说明此固定条件模型对储能电容的敏感性。不能称为最优电容、真实整流器上界、真实器件必要条件、PMIC／冷启动预测、原生模型等价、任务成功、硬件可行或 Agent 收益。100 kΩ 是事先声明的基准假设，不是实测 ESR、芯片参数或拟合值。

## 三个逻辑包与可移植重放

将 core.zip、raw47.tar.xz、raw10.tar.xz 解压到同一个目录，合并唯一顶层文件夹 BF_Conditional_Passive_20261001。各包均小于 10 MiB，无拆分卷依赖；core 含完整旧失败、两份独立审查、新代码／计划／报告，两个 raw 包各含对应电容粗／细轨迹完整输出目录。

运行：

    python3 -B replay.py

这一步仅用 Python 标准库校验完整文件清单、原始封口、源绑定、参数不变与 5/4/1/3 计数。

要重做完整保留数据复核，在已有 NumPy 的 Python 中运行：

    python3 -B replay.py --full

此入口不安装软件，不导入生产 runner，不调用磁力提供器、SciPy、平衡求解或 ODE。仅在内存中重绑定独立审查代码的 BASE/OUT 路径，将结果写入自动清理的临时目录，与 6 份已封口审查输出逐项精确比较。它验证保存轨迹，不重新生成轨迹。原始研究 runner 仅为追溯保留，不要把它作为此交付的 replay 入口。

所有 248 份科学源／结果文件按原字节保留。排除 Python 字节码和审查方的冗余快照副本；完整源代码在两份生产目录内。PACKAGE-MANIFEST.json 绑定全部交付文件（自身除外）；EXACT-BINDINGS.json 给出原始最终封口、源清单、计划与审查的精确 SHA-256。压缩包外层身份见 ARCHIVE-INDEX.json。

## 尚未关闭的边界

实际 PZT 张量／ROM 适用性、未标定阻尼、被舍弃的轴向和弯曲坐标、电压和力相关轴向运动、实体装配、真实初态／复位与负载均未验证。下一步应取得可验证的真实电路／PMIC 引脚端口、辅助储能及电流／轨电压证据后，才能提出启动或任务问题。此被动基准再增加扫描不能补齐这些原生证据。

保留 47 µF 作为对照，10 µF 仅是本模型下的一个条件候选；这不是自动开展电容扫描或改变产品设计的授权。
