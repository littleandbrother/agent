## 唯一改变：返回给模型的反馈字段

反馈开关为 `feedback_level`，取 `original_p` 或 `gateway_only`。初态反馈和每次后续评价均应用同一开关；科学评价器仍保存完整真值，最终通过标准完全相同。

| 字段 | original_p：原 P | gateway_only：剥离反馈 |
|---|---|---|
| 完整通过标记 | 保留 | 保留 |
| 四次目标及时交付数 | 保留 | 保留 |
| 未匹配或多余接收记录数 | 保留 | 保留 |
| 应力、位移连续裕量 | 保留 | 保留 |
| 运行掉电数及其裕量 | 保留 | 隐去 |
| 电压与就绪时刻 | 最高储能电压、7.99 s 储能电压、主/辅梁峰值电压、包络峰值、首次到达启动门限时刻 | 全部隐去 |
| 固件阶段计数 | WAKE、BOOT、SAMPLE、INFER、CONFIRM、REJECT、SAVE、TX、ACK、RECEIVED、BROWNOUT | 全部隐去 |
| 实际幅相、逐事件窗口、能量分项、原始轨迹、隐藏因子、全域上界 | 不提供 | 不提供 |
| 评价 ID、当前提交设计、剩余评价次数等操作元数据 | 保留 | 保留 |

剥离组沿用宿主原有的 `pass_`、`terminal.delivered_on_time`、`terminal.false_reports`、`slack.stress`、`slack.travel` 等字段名称，不靠改名引入另一种提示条件。交付数已知目标为四次；不需要给出内部阶段事实来解释未通过原因。

这里的 `gateway_only` 是实验标签：它仍保留机械安全裕量，并非声称真实网关能测出应力和位移。该对照测的是“保留末端服务与安全反馈，剥去内部电压和程序执行反馈”的整体效果。

## 原判定与本轮指标

完整通过仍要求五项同时成立：四次目标均在各自 250 ms 内收到一条记录；没有多余接收记录；全程零运行掉电；两梁轨迹峰值应力不超过 40 MPa；两梁轨迹峰值位移不超过 1.5 mm。`4/4` 指四次事件交付，并非只有四项判据。

主要结果分别记录“六次预算内曾找到完整通过方案”和“最终明确选择自身已验证通过的方案”。同时列出首次通过所用评价次数、每题四条件结果和设计变化，检查改善是否对应正确调整主梁、辅助梁、门限或储能。运行中断或没有最终提交不改写为物理无解。

主比较是每个计算组内，同一九题的 `original_p` 对 `gateway_only`：报告只在原 P 成功、只在剥离反馈成功、两者成功、两者均未成功的配对数。每格一次的九题先导不使用“100% 确证”措辞。

## 结果怎样解释

1. 如果同轮原 P 明显优于剥离反馈，说明被移除的内部信息包在这批任务、六次预算下有用；结合动作轨迹可说明它帮助了哪些诊断。
2. 如果差距很小或剥离组仍然高通过，应接受这些原题可由主动试验、名义模型或稳健设计解决，不能强说内部探针必不可少。
3. 如果两组均低，先看同轮对照、搜索动作和实际结局，不能把低成绩自动归因于观测混叠。
4. 本轮同时移除电压/就绪时刻、程序计数和掉电摘要，只能检验该信息包的联合价值，**不能区分 I2 与 I3 的独立贡献，更不能确定唯一哪一个物理量起作用**。
5. 旧 P 本来也包含这些科学字段。因此，即便本轮发现信息包有用，也不能由此解释旧 P 与新 P 成绩差异的唯一来源；循环、提示和响应/时间预算等历史差异仍存在。
6. 旧 L 的 10/11 与 A 的 9/11 来自 24 次预算、11 个入选配对。它们不是这轮九个不同实例、六次预算的原 P 对照；本轮必须重新运行原 P。
7. 两个不同系统在初态都交付 0/4，不等于六次主动干预后仍不可区分。隐藏差异下的初始观测相同，也不能直接推出某个具体 Agent 必然失败。峰值电压与阶段计数可以帮助缩小原因，但不保证把全部物理耦合变成独立子问题。
