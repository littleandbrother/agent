# E3 / E4 独立收口：哪些算实了，哪些还不能进入正式主表

本轮没有调用实验模型。下面核查的是题目的物理条件，而不是 Agent 胜率。

## 1. E3：16 个“开路峰值好，整机首包反而失败”的反事实成立

16 个实例都保留原直接整流器，背景频率为 43–49 Hz 的固定分层点，机械阻尼用固定随机种子独立抽样。每个实例只让主梁长度在 24–42 mm 中变化，其他机械、电路和固件字段全部固定。

- 每题先求背景频率下的稳态开路电压峰值，再把这个几何点放回完整 30 秒瞬态。
- 16/16 个开路峰值点都只交付 3/4：第一条错过，后三条交付，没有靠误报或掉电换得表面通过。
- 同题只把主梁长度乘以 0.9868，16/16 都实现完整 4/4，并通过其他全部服务检查。
- 开路峰值点首次储能就绪在 9.917–10.803 秒，受载见证在 6.867–7.735 秒；第一条事件在第 8 秒。这是非常具体的因果链：开路峰值不是首包时间最优点。
- 361 点区间扫描加峰值细化，与另一种独立差分进化算法复算的最优长度最大相差 0.000001651 mm。不是把任意差点贴成“稳态最优”。

文件：`e3_summary.json`、`e3_proxy_optimization_repeat.json`。

这仍然是**单一长度截面的因果校准**，不是在全部几何、电容、门限同时自由时的全球最优性结论。正式 Agent 实验必须对各组开放同样的完整合法域；不能为了保住陷阱，偷偷禁止它通过改变电容或启动门限解决问题。Agent 若自己避开了稳态代理，应该记为真实成功。

## 2. E3：结构“必需”仍未建立，不能把搜索零命中当证明

原参考主梁投影面积为 30×10=300 mm²，辅梁为 18×6=108 mm²。原两梁几何在并排布置下已经是 408 mm²，还没有 PCB、固定端和尖端质量。直接把上限写成 300 mm²，会在开始前排除参考双梁，而不是提供一个自然公平的工程权衡。

还存在一个真实捷径：事件时刻固定时，关闭辅助梁后的轮询策略，可能通过储能就绪时间和轮询周期恰好对齐事件。平均监听功耗大于采能功率，并不能证明这四个固定时刻的检测一定失败。

因此，本轮没有把“全域优化器没有搜到”升级为“模块必需”，也没有凑齐 8+8 个结构任务。E3 的 16 个代理错配反事实可以使用；要求全连续域结构必需的另一半，仍缺有效资格。

## 3. Case 2：分流确实改变机械响应，但不是 SSDI，也不是纯机械单一增益

已找到完整瞬态通过的低压版本：`case2-lowvoltage-0.json`。

- 单主梁、辅助梁关闭，背景 45 Hz / 0.30 g；目标冲击 47 Hz / 0.50 g；四次事件在 12、16、20、26 秒。
- 使用已有的电压阈值电阻分流：阈值 1 V、电阻 47 kΩ，输入变换器等效电阻 300 kΩ。
- 电容 120 µF、启动 2.8 V；包络充电电阻 100 MΩ、放电电阻 20 MΩ；唤醒/重置门限 1.2/0.9 V。
- 完整 4/4、误报 0、掉电 0；记录峰值应力约 38.77 MPa、位移约 0.994 mm；包络峰值约 1.472 V。
- 只关闭分流，同一任务和其他参数不变，得到 0/4、峰值应力约 53.82 MPa。分流还同时改变电压包络和背景唤醒行为，不能把全部交付收益都说成“机械阻尼提升”。
- rtol 减半、最大积分步长从 250 µs 减到 125 µs，低压版本仍完整通过。

更早的 12 V 理想比较器输入原型没有覆盖或包装成实际可接电路，低压版本通过现有 RC 参数实现衰减。这里模拟的是电压触发的电阻分流，不是同步开关 SSDI，不声称应力必然减半。允许大范围改变几何后是否仍然“必须使用 D”，本轮没有证明。

## 4. E4：16 个有解见证成立，窄窗资格未成立

`e4_summary.json` 中 S1 的 16 个实例都有完整 4/4 见证。但本轮没有测出它们的可行区间宽度，更没有证明“非常狭窄”。`narrow_window_qualified=false` 是有意保留的状态，不能在论文中把“有解”改写成“窄窗困难题已通过出厂校验”。

## 5. E4：16 个 S3 的受限域不可行证书是真证书，范围也必须写完整

每个 S3 的首事件在 0.15–0.20 秒，之后在 16、21、26 秒还有三条事件。已有轨迹确实得到 3/4，其他安全、误报、掉电检查全部通过；不是把分类阈值降低到明显不可能的信号强度。目标激励仍大于 0.48 g。

### 证书覆盖的设计域

- 主梁长度 24–42 mm，辅助梁长度 11–24 mm。
- 两梁的尖端质量、宽度、材料、厚度、机械阻尼固定为题目给定值。
- 储能电容 300–1000 µF，启动门限 2.9–3.2 V。
- 零初始机械、电学和储能；不允许外部供电或另加预充电储能。
- 可以选择直接整流、已有输入变换器以及 A/B/C/D 的组合；各支路不能凭空向储能母线注入能量。
- 所有其他字段固定，不能把这些结论外推到更大尖端质量、更低阻尼、更小电容、更低启动门限或新型有源能源。

### 推导

对每根梁，输入项和机械阻尼满足：

`-a·m_force·v - c·v² <= a²·m_force²/(4c)`。

这是配平方的不等式，不依赖测过多少点。机械与压电端的交换能量相消，整流、分流、计算和泄漏不能给母线产生净能量。从零初始能量积分，截止时间前可积累到储能电容的能量不超过：

`E_upper(T) = integral_0^T a(t)² dt × sum_over_beams max_domain[m_force²/(4c)]`。

对固定材料、截面、尖端质量和阻尼，记 `m_force=M+aL`、`m=M+bL`、`k=K/L³`，则：

`m_force²/c ∝ (M+aL)² × L^(3/2) / sqrt(M+bL)`。

其对数导数为：

`2a/(M+aL) + 3/(2L) - b/[2(M+bL)] > 1/L > 0`。

所以取各梁最大允许长度就覆盖整个连续长度区间，不能只用“最大测点”代替全域上界。加速度平方积分采用 L2 三角不等式和正弦平方积分的解析上界；去掉脉冲边缘的衰减只会把界放宽。

16 题中最大的解析输入能量上界为 **1.084822 mJ**。而任何允许设计第一次达到最低启动门限都至少需要：

`0.5 × 300 µF × (2.9 V)² = 1.2615 mJ`。

因此在首包截止前连启动都不可能，更不可能完成全部四次按时交付。后三条能成功不推翻首条不可能。这同时解释了“3/4 近可行”与“4/4 严格无解”如何同时成立。

文件：`e4_summary.json`、`e4_bound_arithmetic.json`。数值积分仅交叉检查算术；不可行依据是上述覆盖域的不等式。

### 这还不是原域下的正式“封喉题”

300 µF 的电容下限和 2.9 V 的启动下限，是本轮为形成简单清晰证书选择的新题目范围，**并非从原五变量 80–1000 µF 的范围或独立器件需求自然推出**。因此它们是“明确受限域的证书校准例”，不能冒充原域不变的全分支物理无解；正式采用这个下限，需要独立的硬件/服务依据，不能仅因为它让证书成立。

此外，第一事件非常早、零初始能量、电容下限与启动门限都在公开规格里。强通用 Agent 若掌握同一物理模型，完全有可能自己推导这个界。可直接算掉并不是坏题，但它不支持“隐藏难题”“模型普遍不会判断”或“必须调用我们的证书工具”的结论。只能以后续公平实验实测。

## 6. 当前没有完整校准好的 S2

S2 需要同时具有：当前分支全域无解的有效排除依据，以及其他合法分支完整通过的见证。本轮还没有这两项同时成立的数据，因此 S2=0。不能用 S1 或 S3 改标签补足 16 道，也不能把某个固定设计关模块失败等同于整个分支无解。

## 7. 代码与公开输入

`structure.py`、`stopping.py` 共用同一个完整消费者，没有新 Agent 框架、哈希准入、供应商账本或仿真替身。校准摘要包含私有见证和证书，供人工审阅；`e3_public_tasks.json`、`e4_public_tasks.json` 不把通过见证、状态答案或证书直接塞给基础组。正式实验仍须按各信息条件选择公开字段，不能把校准文件原样给 Agent。

结论：E3 的代理错配反事实与 Case 2 低压分流设计已经成立；E4 的受限域能量证明成立。完整的结构必需任务、S1 窄窗任务和 S2 分支切换任务仍不能声称完成。任何 Agent 的优势百分比都尚未测量。
