32 对（64 半题）全部通过下列题目校准。没有调用 Agent 或付费模型。

|---|---:|

## 题目到底改变什么

- 电容轴：标称 C ∈ [80,1200] µF，初态 400 µF；私有实现为 `实际 C = 标称 C × bank_factor`。大倍率是电容银行实现/装配故障，不冒充普通器件容差。
- 质量轴：标称附加质量 m ∈ [2,7] g，初态 4.65 g；私有实现为 `实际 m = 标称 m + attachment_offset`。
- 每对两半复用同一公开规格、初态设计与环境；只有私有实现因子不同。其他设计字段固定。32 个独立单位是随机实现因子对，环境共同固定；同对两半不作为独立样本。
- 左右半顺序用独立 seed=20261115 置换；公开 JSON 不含私有方向、因子、见证或区间。此置换不改变任何物理输入或结果。
- 所有初态公开反馈都为 `pass=false, delivered=0, expected=4, false_alarms=0, safety={stress:true,travel:true}`。内部阶段、电压和相位均不在 F0 中。

## 连续域如何校验

先在实际物理参数坐标上各扫一次，再按公开变量与私有实现因子的代数关系映射回 64 个标称域；没有为每半重复同一物理扫描。完整原消费者覆盖两套错位网格，C 最大间隙 5 µF、质量最大间隙 0.05 g；每个观察到的边界二分 7 轮。随后在两边界内外及区间中心，用 `rtol=5e-7,max_step=0.0000625` 做独立重算。

| 实际物理参数 | 验证通过内区间 | 两侧 FAIL 边界外括号 | 单边括号宽度 |
|---|---|---|---|
| capacitance | [76.061638121, 170.475700621] µF | [76.022575621, 170.514763121] µF | 0.039062500 µF |
| mass | [4.491647861, 4.738132236] g | [4.491257236, 4.738522861] g | 0.000390625 g |

物理必要排除界：零初始能量、被动整流/负载下，机械输入满足 `dE/dt ≤ a²·m_f²/(4c)`。对两梁与首事件截止时刻 8.25 s 积分，能量上界为 0.002900485088 J，故实际 C > 689.770532 µF 不可能及时充至 2.9 V；同一界排除实际质量 < 1.416257236 g。其余实际轴域由上述完整瞬态网格与边界复算覆盖。

这是有明确精度的工程数值区间校准，不是经过区间 ODE 验证的数学全域定理，也不是自由编辑全部 14 个变量后的全域不相交证明。未来实验只能将它用于公开声明的固定单轴域。

## 真实计算量与复现入口

- 本轮新完整瞬态 **438 次**：272 次双网格扫描 + 28 次边界二分 + 10 次独立分辨率复算 + 64 初态 + 64 交叉。
- 64 个本方向见证在代数上都对应同一实际 baseline（C=150 µF、m=4.65 g、其余字段与 TASK 相同），复用已经执行的 `outputs/report/case1.json + case1_trace.npz`；没有把它们记为 64 次新调用。
- 本轮真实总墙钟 1947.589 s；逐完整输入记录的求解耗时之和 7607.218 s（四路并行，不能当总墙钟）。0 模型/API 调用。
- `active.py` 是可重现生成与校准入口；从干净输出运行会先计算一次共同 witness，再复用 64 次，因此从干净执行是 439 次新完整输入。
- `e2_public_tasks.json` 供未来运行器读取公开任务；`e2_tasks.json` 的 private 部分只能由物理宿主持有。未来 evaluate 入口只接收该轴单一标称值，其他字段从 initial 固定。
- `e2_axis_validation.jsonl` 保存 310 次原消费者区间输入及完整紧凑检查/能量；`e2_axis_bands.json` 保存物理界与边界括号；`e2_calibration.jsonl` 保存 192 个初态/本方向/交叉结果。
- 原先只有两个见证点的开发记录保留为 `e2_development_*`，不再用它代替当前连续域验收。

本校准只证明成对题物理与观测条件满足；不预设任何 Agent 的通过率，也不将首提不可同时命中推成六步总体通过率必定 50%。
