## 哪些机制真的进入了行动

### 1. 相位确实能提供主梁调谐方向，但不是自动解题器

`B/A1-E1-offset/PA/r1`：先测36mm与42mm，模型明确使用“+11°与−131°”判断45Hz共振区间，第三步把主梁调到40mm，保持C=80µF、启动2.0V，完整服务4/4通过。该记录支持：相位进入了实际选点，能帮助模型离开“越长越好”的方向。

但同一初态的`PA/r0`也读到了相位，先试38mm，随后回到42mm并反复调整C和启动门限，最后41mm/C120只交付3/4且欠压1次。**提供相位和正确持续使用相位是两件事。**不能仅凭字段可见就说它已完成可靠的共振定位。

### 2. 目标频率幅值也有用，不能把PA全部解释成“相位符号的功劳”

`B/A1-T2-nominal/PA/r0`比较目标响应约0.218V与较大的全局包络，判断辅梁偏向干扰频段，直接从16调到17.5mm，一步4/4。理由使用的是目标响应幅值，不是具体相位值。本轮PA同时包含幅值和相位，没有再拆二者。

### 3. 事件窗口能区分“有电却没有在目标时刻唤醒”

`B/A1-E2-offset/EW/r0`第四步已经把主梁调到35mm：首次事件前储能约3.302V、冷启动约2.127秒，全局WAKE=2且REJECT=2，但四个目标窗口的唤醒列表全为空。模型据此将剩余问题转向触发，恢复辅梁18mm、触发门限降到0.2V，第五步完整4/4。这里供能修复和目标触发修复是两个不同环节。

`B/A1-T2-nominal/EW/r0`也明确读取了目标窗口没有wake，调整辅梁；第一步20mm未过，第二步17.5mm才通过。窗口改变了行动，但没有保证第一次判断正确。

### 4. 成功找到解不等于事前正确预测了成功

`B/A1-E2-nominal/EW/r0`第四步测试30mm时，本想验证“33mm已经是峰值，30mm会更差”；结果30mm直接4/4。**这是一个有效反证性探针，不是事前正确算出了答案。**通过事实值得保留，错误预测也应保留，不能把两者写成同一个成果。

## 两种反馈下都出现了错误的全域无解

- `B/A1-E2-offset/PA/r0`只根据24/33/42mm等有限点，认定33mm最佳、整个合法域储能上限不足，第四动作后宣告全域不可行。同批EW在35mm通过，直接反驳此结论。
- `B/A1-E2-nominal/EW/r1`把33mm称为“全局最优”，未测30mm便宣告全域不可行。同题PA两次都在30mm通过；EW/r0也在30mm通过。

两次均非工具错误。模型正确看到了当下设计的电压不足，却把**当前点/已测点的上限**变成了**整个参数空间的上限**。幅相和事件窗口都不能自动阻止这种外推。

## 本轮可以给出的回答

**D的效果不需要全套新增字段才能出现：只加幅相已救回5对，只加窗口也救回4对。**主梁案例有直接的相位→选点→通过证据；窗口有目标时刻未唤醒→修触发→通过证据。两类事实各有作用，不能将D统一解释成“多了一条电压曲线”，也不能说仅靠相位符号就足够。

**剩余卡点在信息到决策之间。**同一幅相事实能被正确夹住共振区间，也能被忽略后退回边界调参；实际电压上限也会被错误外推为全域上限。本轮不证明额外能量账本必需，也不证明D其他字段无用；没有补组或为了追正结果改任务。
