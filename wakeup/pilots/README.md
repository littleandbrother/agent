# Agent 边界预实验 A–L + X：结果与复现确认

代码：`../world.py`（参数化采能节点世界、题目生成、Layer-0 卫生检查）与 `../pilots.py`（Agent 运行、统计）。模型 `deepseek-flash`（思考 high），L 族另用 `deepseek-flash` 关思考与 `deepseek-v4-pro`。每条轨迹独立上下文，最多 6 次正式评价（F 族 3 次）。

```bash
python3 world.py                     # 生成第一阶段题目并做卫生检查 -> tasks.json
python3 world.py --confirm <cell>... # 每格 8 个新实例（新的源频率与唤醒包络）-> confirm.json
python3 pilots.py --run              # 第一阶段，每格 3 个种子
python3 pilots.py --confirm          # 确认阶段，每个新实例 1 条
python3 pilots.py --report           # -> summary.json
```

## 判定规则

- **基础设施失败**（超时、HTTP 500、连接中断、进程被杀、机器重启）一律不计入科学结果，已尽量重跑；仍未解决的 6 条单列为 `infra`，不进分母。
- **结论**必须同时满足：第一阶段出现效应，确认阶段每个对照格 ≥ 8 个新实例（每个实例换源频率与唤醒包络，即变体题）仍复现。否则只记为 **迹象 / 未复现**。
- 区间为 Wilson 95%。每格样本小，区间宽，只报告方向一致且区间分离或 Fisher 检验显著的差异。

## 总体数字

- 有效终态轨迹 **316** 条（第一阶段 + 确认），另有 6 条基础设施失败未能补跑；历史上共 44 条终态与 88 次请求属于基础设施失败，已全部排除。
- 1,531 次有用量的请求；输入 14,462,773 token（缓存命中 13,694,842），输出 6,207,912 token（其中思考 5,758,462）；单次最大输出 26,116，**0 次输出截断**，27 次格式错误已返回纠正。
- 费用（官方高峰价估算，不是账单）：有用量请求按不计缓存为 **USD 13.24**，计缓存约 **USD 8.46**；88 次无用量请求按每次 65,536 输出 token 全额预留计 USD 6.92，最保守合计 **USD 20.16**。超出 20 美元保守上限 0.16 美元，原因是运行中超时没有计入实时账本（只在重启时计入），已在 `pilots.py` 修正。实际花费远低于保守值。
- J 族（评价预算 6/20/50）因预算未运行。

## 已复现的结论

### 1. 反事实物理且不给定律时，Agent 基本失败；给定律就不失败（A 族）

| 对照 | 通过 | Wilson 95% |
|---|---:|---|
| 真实物理 + 给定律（text，确认 16 个新实例） | 16/16 | [0.806, 1.000] |
| 反事实物理 + 不给定律（counter_hidden，确认 16 个新实例） | 2/16 | [0.035, 0.360] |
| 反事实物理 + 给出反事实定律（counter，第一阶段） | 6/6 | [0.610, 1.000] |
| 反事实物理 + 不给定律（counter_hidden，第一阶段） | 1/6 | [0.030, 0.564] |

确认阶段 Fisher p < 1e-4。给出反事实定律时全部通过，所以困难不在反常物理本身，而在**只靠评价反馈辨识未知定律**。

**失败机制**（读 19 条失败轨迹）：
- 第一步 16/16 都按教科书先验加大质量去降低谐振频率，在这个世界里方向是反的。
- 谐振律因为 `resonance_Hz` 直接可见，1 到 2 步就被纠正。19 条失败里有 11 条最终几何完全正确：谐振对准，质量顶到上界，和私有最优解一致。
- 剩下没辨识出来的是只能通过总采能间接观察的电学规律，即最优负载和冷启动的储能 / 阈值搭配。几何正确的 11 条里，负载是最优值的 0.5 到 2.6 倍；给定律的 text 组 8/8 恰好等于最优值。模型的理由仍是先验（例如“更大质量 = 更大驱动力”，“thinner beam raises V_oc”），没有设计能分离单一因素的探测。
- 这说明边界在于**可观测性**：直接可见的量可以纠偏，被多个因素混合后才可见的量，就沿用先验。

### 2. 失败时的“不可行”判断与真不可行无法区分（G 族 + 全体可行题）

- 真不可行题（G、L/G、X/G）33 条，27 条给出 INFEASIBLE，平均置信度 **0.854**。确认阶段 15 条中 11 条正确，其余在预算用尽前没有作答。没有一条声称可行。
- 可行题里失败 42 条，其中 15 条给出 INFEASIBLE，平均置信度 **0.884**；没有一条给出 UNSURE。两组置信度没有差别（Mann-Whitney p = 0.27）。
- 所以 INFEASIBLE 的精确率只有 27/42 = 0.64，区间 [0.49, 0.77]。错判不来自单一格：第一阶段有 9 条，确认阶段独立复现 6 条，覆盖 A/counter_hidden、H/prims/stress、H/menu/stress、E/stress、B、K、D。
- **机制**：模型把“在我试过的几个点上，能量和应力互相冲突”推广成了全域不可能，理由里常有“mutually exclusive”“cannot be met at any operating point”。它没有区分“我搜索过的子空间”和“整个设计空间”（包括没有尝试的模块组合）。会说“不可行”不代表会判断不可行，这是本轮最接近核心的发现。

## 注意事项

- 世界是闭式降阶模型，可行余量由人为设定（0.1 到 1e-5），不是器件认证；结论的范围是“这个接口 + 6 次评价 + deepseek-flash”。
- 确认实例只改源频率与唤醒包络，所以是同构变体，不是不同物理题。
- 关键词召回是粗指标；A 的失败机制来自轨迹阅读，“质量向上”的首步方向在 text 组同样成立（那里是对的），所以只能说明首步依赖先验，不能单独证明先验有害。
- 6 条未补跑的基础设施失败集中在 H/prims/stress（3 条）、G/stress 与 E。

## 推荐第二阶段

1. **A 的关键对照**：加 `text_hidden`（真实物理、不给定律），用来区分“先验误导”和“只是缺少定律”。同时加一档“电学输出直接可见”，检验可观测性是不是真正的变量。
2. **不可行性校准成为主线**：构造难度匹配的成对题（可行但很窄 / 刚好不可行），测 INFEASIBLE 的 ROC 与置信度；再测两种干预：要求给出覆盖整个空间的不可行论证，或提供全局上界工具（X 证书）。
3. 补齐 H/prims/stress 的 3 个确认实例，并加深配方（3 件以上原语、带时序）。
4. B 的工具效应做 8 实例确认；J 预算族与 L 模型尺度在主线确认后再跑。
5. 工程项：把单次请求超时从 600 s 降到 300 s，并用观测到的最大单次输出给无用量请求计费，避免保守账本过度膨胀（本轮 88 次无用量请求占了保守账本的 34%）。
