## 1. 研究问题和三条定理

研究总问题是：在真实压电唤醒节点的全瞬态仿真上，大模型 Agent 的工程设计能力边界在哪里。上一轮较宽松的题和较大评价预算上，通过率容易触顶。用户推导把这件事切成三个互不替代的层次：物理上有没有解、当前观测够不够决定下一步方向、已有失败记录排除了多大范围。下面三条定理分别对应这三层，并落实为 X1、X2、X3。

### 1.1 物理分界：无量纲可行比 χ

固定结构 \(m\) 下，储能电容必须同时大到扛住一次上报的能量缺口，又小到能在首个故障到来之前充到启动电压。简化模型给出

\[
C_{\min}=\frac{2E_{\mathrm{need}}}{V_{\mathrm{on}}^{2}-V_{\mathrm{off}}^{2}},\qquad
C_{\max}=\frac{2P_{c}T}{V_{\mathrm{on}}^{2}},\qquad
\chi=\frac{C_{\min}}{C_{\max}}=\frac{E_{\mathrm{need}}V_{\mathrm{on}}^{2}}{P_{c}T(V_{\mathrm{on}}^{2}-V_{\mathrm{off}}^{2})}.
\]

实现见 `theorems.py` 的 `window()`：`VON=2.9`，`VOFF=1.8`，\(T=t_{1}+0.25-\tau\)，其中任务时延 \(\tau=128/2048+t_{\mathrm{boot}}+t_{\mathrm{infer}}+t_{\mathrm{save}}+t_{\mathrm{tx}}+t_{\mathrm{ack}}=0.072\,\mathrm{s}\)（采样 62.5 ms，加上 boot 2 ms、infer 2 ms、save 0.5 ms、tx 4 ms、ack 1 ms）。\(E_{\mathrm{need}}\) 是一次上报从储能抽取的能量再除以调节器效率 0.85，并忽略约 72 ms 任务期间的采能。\(P_{c}\) 来自 \(C=100\,\mu\mathrm{F}\) 的冷启动仿真：\(P_{c}=\tfrac12 C_{\mathrm{ref}}V_{\mathrm{on}}^{2}/t_{\mathrm{ready}}\)。

判据：\(\chi(m)\le 1\) 当且仅当该结构存在电容窗口；\(\chi(m)>1\) 则该结构无论怎么调 \(C\) 都没有解，必须改结构（提高 \(P_{c}\)）或改能量 / 时限。X1 要检验的，就是这条简化分界与全瞬态真值是否对齐，以及 Agent 在 \(\chi\) 穿过 1 时会不会从「只调电容」转到「改结构」。

同一节还给出代理保序条件：常用代理 \(P=\eta V_{\mathrm{oc}}^{2}/(4R_{s})\)。当 \(R_{s}\) 随几何变化、或受载充电拖延 \(t_{\mathrm{on}}\) 时，\(V_{\mathrm{oc}}\) 的极值可以与整机功率（因而与 \(\chi\)）反序。X1 在出厂校验里放了「Voc 峰值质量 vs 功率最优质量」对照，但没有单列成 Agent 臂（见第 4 节）。

### 1.2 信息分界：同症状下的 50% 上限与先测规则

若两种隐藏状态 \(\theta_{A},\theta_{B}\) 在基础反馈 \(h\) 下不可区分，且成功集不相交 \(F_{A}\cap F_{B}=\varnothing\)，则任何只依赖 \(h\) 的策略，单次提交的成功率有

\[
P_{\mathrm{step1}}\le \tfrac12.
\]

同时，若两个方向都可以用一次评价试出来，盲目先试一侧、失败再试对侧，期望评价次数是 \(\mathbb{E}[N_{\mathrm{eval}}]=1.5\)。若诊断代价为 \(c_{m}\)、一次评价代价为 \(c_{e}\)，则「先测量再提交」严格更省，当且仅当 \(c_{m}<\tfrac12 c_{e}\)。X2 把 \(c_{m}=0.2\,c_{e}\)，落在该不等式的「应该先测」一侧，并分开报告首提命中率与期望评价次数。谐振峰两侧的相位诊断（\(\phi=-\mathrm{atan2}(B\omega,\Delta)\)）原计划作为 X2-II，出厂校验未通过，整族放弃。

### 1.3 停止分界：证书覆盖

判定「全域无解」需要覆盖全部合法结构的上界 \(\max_{m}U_{m}<0\)，而不是把已测点的样本极值当作全域上界。连续空间上还可用 Lipschitz 包络 \(U_{t}(x)=\min_{i}[y_{i}+L\|x-x_{i}\|]<0\)。局部排除与全域排除必须分开：仅 \(U_{m_{0}}<0\) 而 \(U_{m_{1}}>0\) 时，正确动作是换分支，不是宣布全题无解。X3 用三种真实状态 × 三种证据范围，检验 Agent 的停止范围是否跟着证据范围走。

预注册还把决策问题写成：客观可行比、歧义配对、停止证书是三件分开的事；\(f=\min_{j}g_{j}\) 只是把「多约束同时满足」写成同一套语言，并不另设第四项实验。

## 2. 试验台、Agent 接口与模型

### 2.1 节点与地面真值

试验台是仓库里的无电池压电唤醒故障上报节点。`design.json` 给出默认几何与电路；`theorems.py` 在每次仿真前把储能箝位改为 `clamp_V=2.95`（刚好高于启动电压 2.9 V），避免 3.3 V 箝位与启动阈值之间的额外混杂。其余固定量与预注册一致：触发梁开启、直接桥式整流、启动 2.9 V、掉电 1.8 V、背景振动 45 Hz。预注册记录：纯轮询、不开启触发梁的结构在所有电容上均不可行（一次 62.5 ms 采样约 0.2 mJ，每次轮询都要付）；提高 \(P_{c}\) 的结构修复是加第二根梁。仿真里的受控变换器支路曾被测过，效率 0.65，并不更好，本实验不用。

评价一律走 `sim.py` 的 `simulate()` 全瞬态，包括出厂校验的标签和 Agent 每一次 `evaluate`。任务（`TASK`，故障时刻由题目改写）：时长 30 s；背景 45 Hz；故障 210 Hz、0.5 g、150 ms，须在开始后 0.25 s 内上报；干扰脉冲 250 Hz、0.8 g、200 ms，不得上报。固件一次上报：boot 3 mW / 2 ms，采样 3 mW / 128 点 @ 2048 Hz（62.5 ms），infer 5 mW / 2 ms，save 2 mW / 0.5 ms，tx 功率由隐藏条件给定、时长 4 ms，ack 3 mW / 1 ms，调节器效率 0.85。分类阈值（目标带 195–225 Hz、最小 RMS 0.12 g 等）仍在仿真里，但本批题目的能量靠近 χ 边界，不再使用「目标只有 0.0003 g」这类分类捷径。

### 2.2 设计变量与结构

功率最优尖端质量由冷启动功率曲线给出：\(m^{\ast}=4.5875\,\mathrm{g}\)，单梁 \(P_{c}=91.274148035598\,\mu\mathrm{W}\)（窗口里记 91.3），双梁 \(P_{c}=178.93617021276594\,\mu\mathrm{W}\)（记 178.9），约 1.96 倍而非精确的 2 倍。

结构约定：\(m_{0}\) 为 1 根采能梁；\(m_{1}\) 为 2 根完全相同的并联梁，各自带桥（`width_mm=10n`，每梁尖端质量同为设定值，`bridge_series_ohm=5000/n`）。X1 / X3 的可调域是 `storage_uF ∈ [20, 1000]`、`harvester_beams ∈ {1, 2}`、`tip_mass_g ∈ [3.8, 5.8]`（梁长固定 30 mm）。X2-I 只允许改 `storage_uF`，梁长 30 mm、尖端质量锁定为 \(m^{\ast}\)。

### 2.3 Agent 看见什么、能做什么

系统提示由 `intro()` 写出，用户消息是当前设计加反馈或历史。题目描述（`describe()`）用英文说明节点与判据。工具是函数调用：

- `evaluate(changes, reason)`：在当前设计上打补丁并跑官方全瞬态。第一次通过即结束。
- `finish(verdict, confidence, reason)`：仅 X1、X3 提供。`verdict ∈ {FEASIBLE, INFEASIBLE, UNSURE}`。INFEASIBLE 断言申报域内没有任何设计能通过。
- `diagnose()`：仅 X2 的 tool 臂提供，代价 0.2 单位，测量当前设计。

评价预算：X1 为 6 次评价；X2 为 4 单位（一次评价 1 单位，诊断 0.2 单位）；X3 为 4 次额外评价（历史中的 4 个失败点不计入这 4 次）。超出预算或已通过则停止。无工具调用的纯文本：X1 / X2 记失败，X3 记为有效但无裁决（`TEXT_WITHOUT_ACTION`）。

反馈口径不同。X1 / X3 返回 `pass`、`delivered_on_time`（k/4）、`brownouts`、`cold_charge_ready_s`、`first_wake_s`、`min_active_storage_V`、解析开路电压 `harvester_open_circuit_V`。X2-I 只返回 `passed`（通过 / 失败），以维持「同症状」。X2 的发射功率和背景幅值在题面里写成 `(unknown, see conditions)`，只告诉 Agent 两个等可能场条件的近似 \(P_{c}\) 与 \(E_{\mathrm{need}}\)。

模型：deepseek-flash，`thinking` 开启，`reasoning_effort="high"`，`max_tokens=65536`，流式读取，`ask()` 读超时 300 s（约束的是无数据静默时间）。账本按官方价目做保守估算（预留按一次请求写满 65536 输出 token 计），不是账单；`BUDGET_STOP` 在「再发出一次最坏请求就会超过 CAP」时触发。排除规则：超时、HTTP / URL 错误、缺 usage、以及 `BUDGET_STOP` 不进分母，并补跑一次。本次 116 条终点全部有效，`unknown=0`，`infra_attempts=0`，无需补跑。

## 6. 解释：结论、迹象、未支持的预测、限制与下一步

### 6.1 稳定结论（仅 X2）

在电容方向歧义、通过集不相交、基础反馈只有通过 / 失败、预算 4 单位、\(c_{m}=0.2\,c_{e}\) 的条件下，对 deepseek-flash（思考 high）：

1. 盲试首提成功率 8/16 = 50%，正好落在定理上界 \(\le 50\%\)，Wilson 区间 [0.28, 0.72]；第一步方向猜对同样是 8/16（H2a）。
2. tool 臂 16/16 都在第一次评价之前调用 `diagnose`，首提 16/16，显著高于盲试（H2b，Fisher p = 0.0024）。given 同样 16/16、p = 0.0024，说明在这批题上瓶颈是信息而不是推理。
3. 平均评价次数盲试 1.875、tool / given 为 1.0（H2c，Mann-Whitney p = 0.0016）。1.875 高于盲目理论值 1.5，是因为 2/16 最终没修好，失败按预算+1=5 计。方向在 8 对中的 6 对成立，满足修订 2 的「多数对 + p < 0.05」。

这检验的是信息论上限和测量代价定律，不是「模型笨」。谐振轴（X2-II）没有做，不能外推到「所有同症状歧义」。

### 6.2 迹象（不得写成结论）

**X1。** 各 χ、两臂的最终通过率都是 4/4，「χ > 1 时只调电容就会失败」没有出现：χ > 1 时两组都改到双梁并通过。更值得注意的是过早改结构：χ = 0.95 时单梁本来有真窗口，base 仍 4/4 改双梁，chi 臂 2/4，且 chi 臂只有 1/4 把单梁电容落到真窗口（base 为 0/4）。χ = 0.6 时 base 已有 1/4 改双梁，chi 为 0/4。χ = 1.8 时 base 4/4 先把质量推向 Voc 峰（轨迹里常见先试 5.8 g 或 5.2 g），平均评估 3.75 次、花费 0.098；chi 臂 1/4 这样做，平均 1.75 次、花费 0.074。给出 χ 似乎抑制了代理指标带偏，但每格只有 4 条，只能算迹象。H1c 因而有描述性支持，却没有预注册的显著性检验。

**X3。** 对实际有解的 S1 / S2，三个证据级别下假 INFEASIBLE 都是 0/24；S2 的 12 条全部改到双梁并找到解，L0 在没有上界时也会换分支。对真正无解的 S3，12/12 都判对。L1、L2 各有 1/4 未测双梁就下无解结论（H3c 只有这一条迹象）；L2 的那一条理由仍被计为「覆盖全域」，L1 的那一条没有。成本上，同样得到 S3 无解，L0 花费 0.291，L2 花费 0.1。「证据越全，判定范围越收敛」在假判 / 真判率上没有差异，所有预注册比较的 p 都是 1.0。

### 6.3 哪些预测没有被支持

- H1b：通过率在 χ 两侧、两臂之间都是 8/8，分界没有变成通过率的分界。题目在 χ > 1 时双梁仍然好解，Agent 又愿意加梁，所以「必须改结构」没有变成「改不出来」。
- 代理反转没有作为 Agent 对照臂实施；即便作为出门演示，也有 2/8 未形成「一败一胜」。
- H3a / H3b：假判已经是 0，真判已经是 12/12，证书阶梯没有向下或向上的空间。S1 的窄窗仍能被 L0 找到（或改双梁通过），没有复现「把局部失败当成全域无解」的旧机制。

未支持不等于定理被否证。χ 分界在无模型的真值扫描上是清楚的；Agent 侧失败的是「用 χ 作为结构开关的行为预测」。停止定理要显现，需要 L0 上确实出现假无解，或 S3 上 L0 无法正确停住——本批题没有提供这种对照。

### 6.4 限制

- X1 / X3 每格 n = 4，合并后每侧也只有 8，只能检出很大的效应；通过率触顶时 Fisher 必然为 1。
- 单一模型（deepseek-flash，思考 high），不能推到其他模型或关思考设置。
- 单一试验台（该压电唤醒节点 + 1 梁 / 2 梁结构）。X2 只覆盖电容方向，谐振方向已放弃。
- X2 半对共享同一对的构造，不独立；结论以「对」为复制单位。
- 花费是保守账本，不是供应商账单。
- 用户推导原文文件缺失，定理陈述依赖预注册摘要与实现，而不是对缺失附件的复述。

### 6.5 可考虑的下一步

- X1：加大每格样本；或限制「不必要地加梁」（例如 χ < 1 时把改双梁算作偏离），才能把结构开关从通过率里分离出来。代理反转若要变成 Agent 臂，应先筛掉双梁窗口过宽、两点都通过的实例。
- X2-II：按修订 2 的失败原因重做同症状谐振对（硬侧在 L0 以下不可过，A / B 可见反馈必须相同），再检验同一条 50% 上限。
- X3：把 S1 做得更窄、或让历史点更像「已经搜过峰值」，使 L0 有机会出现假 INFEASIBLE；否则证书阶梯没有可测差异。可单独追踪「L1 用单梁上界直接宣布全域无解」的比率。
- 换模型或换试验台复现 X2 的首提结果，再考虑写成跨设置的结论。
