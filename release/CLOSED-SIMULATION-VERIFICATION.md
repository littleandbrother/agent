## 改动与可操作入口

- Studio 保留设计对话、产品成果、图片/模型/仿真结论和导出；Lab 保留 Trace、实验、Memory、Harness、Tools 与架构地图。两者共享会话身份，版本交付包记录文件和缺口。
- 新增 `closed-simulation` 工程入口和 `bf_engineering` 的同名 engine。完整输入在 `design-spec.json`，结果区分计算运行状态、模型内预测和产品验收状态。中断、越界、失效缓存和缺失证据不能被标为产品通过。
- 原生计算按参数化 CAD → COMSOL 梁参数与有限磁力表 → 机械/压电/LTC3588-1 联合求解 → 共享 C 程序与负载反馈 → 虚拟接收 → 数值/磁场复核运行。缓存、模型与文件均绑定摘要；单因素修改只使依赖阶段失效。
- 源码含配置、Result schema、测试与说明；未提交本机约1.4 GB的两条工程运行文件。原生重算仍需对应软件、许可证和本机配置。
