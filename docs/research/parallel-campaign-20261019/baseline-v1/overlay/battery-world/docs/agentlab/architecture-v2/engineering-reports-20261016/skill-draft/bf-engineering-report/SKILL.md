# BF 工程报告

当前为待审定草稿；模板位于报告包的 `templates.json`，页序见 `references/pages.md`。

## 执行

1. 读取项目、报告目标 System Commit、采用版、当前资格及选定作业。将报告目标固定在 `report-input.json`。
2. 从文件和预览入口取得资产，核对候选身份、源码及输出摘要。已有有效结果直接复用。
3. 提取尺寸、固件配置、波形和检查结果。字段来源见 `references/data.md`。
4. 按页列缺项并分配专业工作。Lead 组织整机图与结论，Power 处理电气图和能量分析，Firmware 处理状态图与事件数据，机械任务处理尺寸和装配图。
5. 专业任务提交可编辑图源、派生图片、来源对象及输入摘要。当前候选发生改变时重新绑定报告输入。
6. 渲染简版和详版 PDF，逐页检查中文、单位、图片、表格与页脚。提交 PDF、数据、来源清单和检查记录。

## 输出合同

- 简版固定八页；详版按工程内容扩展章节。
- 每份图和每项结果都带来源及候选身份；示意图明确标注。
- 缺失材料进入补齐任务；工程结论使用该候选当前独立检查。
- 事件图核对记录绑定的源码；电源图核对实际 RAW 与选定作业。
- 报告记录 Pi、Codex、人工参与及报告生成耗费。

## 交付检查

核对输入 SHA-256、两类 PDF 页数、字体嵌入、页面边界和版本；对缺项保留负责人及关闭条件。模板引擎提供 `render.py`、`render_native_previews.mjs` 和 `verify.py`。
