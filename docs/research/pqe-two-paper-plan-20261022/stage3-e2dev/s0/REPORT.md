十二次实际尝试全部结束，没有补格、重启矩阵或更换题目。D15、D07 四种方法各自完成服务，M3 四种方法都实际解除暂定约束并重新计算，但均未完成服务。本包支持共同接口和范围修订的实际消费路径；没有建立 full_h 的服务优势、独有范围修订能力或 H/G 学习效果。

### D15：相同局部修复，服务效果不能区分方法

四组都自主只改 `persistent_queue: false → true`，其余 Design 与整个 P 保持不变。四组独立提交同一精确有效输入后，复用原 D15 当前科学版本的结果 `a400e701b2d38ce003c4356ee0f6c87703c199fde41da5747ff8c27866538d0d`。这是四个决策、一份科学结果，不是四次数值独立重复。

独立事件读回支持本例中 IDLE 掉电后的序号保持：接收序列由 `1,2,1,2` 变为 `1,2,3,4`。不能扩大为全部 NVM 故障覆盖。B3 的局部预测记录为 CONSISTENT、`unique_cause=false`；其余组同样完成服务。B0/B3 各使用一次额外 RANK，D15 没有给出 full_h 的服务收益。

### D07：单变量修复足够，联合修复不是必要条件

唯一新增的当前初态 valid/COMPLETE，但 0 接收，755 次启动/复位，其中 753 次发生在 TX、2 次在 IDLE。完整 wire/receiver 均为 0，因此不能把 753 次掉电写成 753 次完整重传。

- B2 只改 `esr_ohm: 60 → 0.1`，一次数值计算即 PASS。
- B3 改电容 `100 → 200µF`、阻抗 `60 → 0.5Ω`、启动 `2.2 → 2.0V`、发送门限 `2.2 → 2.3V`，一次 PASS。
- B0 改电容 `100 → 120µF`、阻抗 `60 → 0.1Ω`、启动 `2.2 → 2.1V`、stroke `8 → 8.5mm`，一次 PASS。
- B1 前两次分别触及 assembly envelope / cam pressure-angle 限制，记录为 MODEL_DOMAIN UNKNOWN；第三次恢复有效机构配置后 PASS。最终电容 150µF、阻抗 0.1Ω、启动/发送门限均 2.8V，机构显式写出的 7mm/8mm 对应原默认几何。

B1 随后两次 select/report 是 NO_EXECUTION、NO_NEW_ASSESSMENT，字面返回 UNKNOWN，不覆盖此前适用的科学 PASS，也不算两次数值失败。所有这些中间结果保留。D07 的现有结果反对“必须同时改变多个变量才能修复”的先验，不能拿联合改动的成功证明联合改动必要。

### M3：四组都有实际 P 消费，尚无完整服务改善

原半速 Task、服务要求、科学消费者与独立评价器不变。四组都在已执行动作中把 `startup_v`、`mechanism` 加入 active variables，清空相应 fixed choices，使用 1.9V 启动与 8.5mm stroke，再重新计算。原初态 0 启动；部分新候选可以启动、捕获或保存，但 7 个实际候选全部 valid/COMPLETE、0 接收、FAIL。

B2 测试 80µF 与 800µF 两个候选；B3 在其它相关输入相同的三次计算中测试 100µF、1mF、50µF，分别呈现 TX 掉电、无法启动、SAVE 掉电。B0 测试 80µF，B1 测试 82µF。原始动作、P 前后字段和逐次结果见 RESULTS.json 与对应 episode，不用文字意图代替实际消费。

这些事实证明范围修订已被消费者执行，且可以改变中间行为；它们没有证明完整服务收益，也没有显示 full_h 独有这项能力。B0/B2/B3 的最终范围明确限定在已测设计。B1 以“必须在首次开门 crossing 前启动”为前提，导出电容充电上界与 TX 下界不相容，再将结论扩展到全部合法设计域；程序和 2s 服务期限不要求这个启动截止。保留其真实 FAIL 与原始论证，全域完整服务继续 UNKNOWN。指出证明前提不足，不代表已经找到可行设计。

A 还区分了两种文字/引用情况：M3 B0 说“raising capacitance to80µF”，实际是从100µF降低到80µF，方向描述错误但其 FAIL 有独立依据。D07 B3 的 `5f3d…` 是实际 compact public Result 对象哈希，内嵌的科学 raw result 为 `5e454…`，两个身份重算吻合，不是证据引用错配。原模型文字均保持。

## 共同接口、原始错误与实际成本

四条件使用同一公共 Task、初态、完整合法动作权限、外部评价器和预算。B0/B3 实际 GEN+模型 RANK，B1 按冻结操作优先级局部选择，B2 先承诺生成候选后作局部选择。默认 UPDATE 为本地事实/预测更新，实际模型 UPDATE=0，没有运行 H/G 方法形成。

入口首轮 10 个测试方法有 8 个通过，另两项暴露 fixture 问题：预测引用的 `facts.fixture_value` 被现行公共投影滤除；`Episode.__new__` mock 漏设 server。原失败 JSON/log 保留。明确例外 `BF-PQE-E2DEV-FIXTURE-EXCEPTION-001` 只修两处 fixture，S0 仅对失败两方法各复查一次（parser 保留原 9 子场景），均通过；没有重跑全 suite、放宽投影或增加生产修订/研究额度。B 独立入口放行后才冻结和执行。

实际 M3 B0 首个 GEN 将 observe 与非空 Design edit 放在一起，得到 READ_ACTION_HAS_EDIT 公共反馈且没有执行。模型在原预算内自行重提合法 edit，再 RANK、执行和停止；原付费请求与原 payload 都保留。实际字段恢复共 1 次，实际 JSON_SYNTAX_ERROR=0；语法恢复仅有离线 fixture 证据，不能算真实格式恢复成功。

39 笔全部 SETTLED，输入 674,698、输出 299,723 tokens；按既定费率估算 USD **0.562077**，不是发票核验。没有新增 UNKNOWN/缺用量。12 个临时参与者 token 已撤销、grant/study 已过期、预算 scope 恢复，活动锁已移除。原 R11 整行 hash 前后相同，UNKNOWN/null usage/原预留保持，无重试。

A 的离线 checker 曾误把公开 Task 投影与完整 host Task 直接比较而报警；现已分别对照事前冻结的公共材料与完整 Task 哈希纠正。原误报 hash 和修正原因写入 A 收据，没有改科学数据、重读 raw 或新增执行；它不计为参与者失败。

## 保留边界与下一有限配置

完整阶段二、正式 E2/E3、H/G 学习与迁移、硬件接受均未由本包完成。旧 M3 包的“没有实际 P 动作”保持其历史事实；本包新增了四组实际 P 消费证据，尚不能据此关闭所有阶段或建立所提方法的因果优势。

不继续扫这三道已见题追正例。下一正式 E2 的有限配置建议为：4 个事前冻结的新 Task × 4 方法 × 2 次独立参与者会话，最多 32 格；继续同权限/预算/科学消费者、按 Task 配对，使用精确缓存但不把缓存当独立科学样本。实用差异事前定义为同预算至少多完成 1 个 Task，或服务不降而每 Task 少用至少 1 次新数值，并且不增加错误的全域排除。4 个 Task 不能预先保证统计功效或泛化结论。

这个候选配置上限为 USD128、196 次新耦合（最多4共同初态+32×6）、原生0、保留400MB/峰值1GB，必须另有明确有限工单，不能转用本包余量自动开跑。E3 的目标 Task 应在 G 接触训练经历前冻结；G 可用真实公开开发经历，不接收本次 host 私有终评或未来目标答案。当前不创建新包，不运行 H/G、不恢复定时任务，不 commit/push。

本批所有原始实验、失败和必要费用记录保留，复用原环境与源树，没有新增备份、环境或工作区。存储实测、生成文件清单及保留上限核对见 postflight.json；本研究包没有删除操作，释放空间为0，不把此前清理的释放量重复记入本批。
