# 联合搜索算法改写与前瞻比较

派发：BF-PQE-ACTION-POLICY-20261024-001。依据用户持续推进、完成即回报及“大范围改动测试、减少反复准备”的授权。上一包 TRAINING-EXECUTION 已独立收口，原失败、代码、拒绝、费用及未执行格保留。S0 统一安排 A/B；本包是一次共同起点调整、自动算法编辑、完整训练和前瞻比较的连续工作，不把任何接入检查作为等待审批的终点。

## 1. 研究判断与这次实质改变

旧父方法按固定比例生成 source/reserve/program/contrast，顺序执行时 Rank 缺批量候选结果便取第一项。H2 写入的新状态未被行动算法消费，H4 修改停止规则反而使已经通过的 DOOR 继续行动直至模型域失效。两组有六位点权限，但8759字符 Generate 与3167字符 Rank 在实际形成输入中变为分页引用，模型均未读页；短 Update/Stop 直接可见。这是表示诱因和算法缺口，不是代码编辑能力不存在的证明。

不继续围绕旧 Update/Stop 加防护。改为：复用既有强通用工具 Agent 的实际模型决策能力，作为所有组共同的、可编辑的父方法；模型可根据当前任务、合法域、完整服务反馈与同一历史提出新的联合设计，而非限于旧四模板。然后比较普通自动代码改进与工程决策归因改进能否在这个起点上改善实际搜索和完整服务。

共同父的变化是开发者实现，不计作自动学习收益；旧父结果不能冒充新父对照。两种改进器获得同一父代码、六位点权限、历史、任务、模型、工具和形成预算。可以联合改 Generate/Select/Update、采用可计算关系、条件化历史或调用模型；不强制特定规则、参数或正确答案。允许无提案、行动不变和负结果。

假设：在完整决策代码直接可见、父方法具有自主联合搜索能力时，自动程序改写能将工程经历变为被后续行动消费的策略，并在新工况提高完整服务或降低包含学习的总成本。
反证：编辑仍不改变行动；仅复制已见参数；行动改变但没有完整服务/总成本收益；在父通过处退化；或强通用父同样有效。所有情形均可收口，不扩同题矩阵追正结果。

## 4. 先实际运行共同父，再连续训练两种自动改进

公开材料是同一现有完整开发历史，包含真实成败与LC三套工程PASS，逐项标明开发者方案/Agent行动/模型结果。不得只向归因组提供修复提示。两道训练题复用上一包公开DOOR控制和LC失败任务，原始科学输入/成功缓存复用。

新父先在这两道开发题实际决策，每题最多2个候选；这2次episode也有完整费用与行为记录，不借用旧固定父轨迹。结果加入两组相同开发历史，作为新父训练参照。若新父直接用公开成功案例完成任务，照实记录，这正是强基线应有的能力；不削弱它以制造学习收益。

## 5. 冻结后，三组在同四题独立比较

条件为：同历史强通用父、普通自动代码后代、归因自动代码后代。形成结束冻结全部程序，合并两组公开训练经历给三个条件同等可达，之后不得返回形成器继续修改。

四题每条件各一次独立solve，每格最多3个已评价候选含缓存；同模型、公共工具、合法动作、事实权限和求解上限。新题结果彼此隔离，不因前一题表现修后一题。父必须真实重新决策，不能用旧轨迹充当新共同历史对照。精确科学输入命中缓存记reused；节省额度不补组。

同时报告：
- 完整服务/正确停止，及模型域和工具执行状态；
- 修改了哪个实际函数，哪些新状态被行动函数读取；
- 提案、选择、真实执行和完整后果的对应；
- 直接复用已见设计与按新条件重新设计的区别；
- 包含全部提案、拒绝、训练、筛选、修订及求解的成本。

最终采用仍要求范围正确、四预定题完整服务且父通过处无退化。父未全过而子全过可以作这一范围的条件采用；父子都全过，只在包含形成与训练的总成本更低时按成本采用。其他情况保留父。四题为有限前瞻比较，不称普遍优势、独立形成多次G比较或RSI。无增量即冻结负结果，不自动再开相同改字段包。
